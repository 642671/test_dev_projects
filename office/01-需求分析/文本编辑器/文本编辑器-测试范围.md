# 文本编辑器 - 测试范围

## In-Scope（本轮测试范围）

| 模块 | 包含功能 | 优先级 |
|------|----------|--------|
| 首页优化 | 多标签页管理、关闭功能、打开文件校验、大文件分块加载、右键菜单、新建文件 | P0 |
| 行与列编辑能力优化 | 行操作/列操作/撤销重做/底部状态栏 | P0 |
| 新增文件下拉菜单 | 新建/打开/最近打开/保存/另存为/全部保存/标签页管理 | P0 |
| 新增查找与替换功能 | 查找/替换/正则/模式开关/大文档性能/只读处理 | P0 |
| 新增编码格式48种 | 编码自动识别/编码切换/另存为编码选择 | P0 |
| 新增语言格式100种 | TextMate引擎/100+语言高亮/语言自动识别/状态栏切换 | P0 |
| 新增设置面板功能 | 设置面板/显示模式/隐藏字符/缩进参考线/自动换行/自动保存/持久化 | P0 |
| 新增文本缩放功能 | 缩放范围/下拉菜单/Ctrl+滚轮切换/缩放记忆 | P0 |

## Out-of-Scope（本轮不测）

- 代码折叠
- 文件拖拽打开
- 多标签页拖拽排序（跨窗口）
- 移动端适配
- 多用户并发编辑冲突处理
- 用户自定义主题
- 性能压力测试中的极限并发场景

## 依赖项

- Monaco Editor API
- TextMate Grammar 规则文件
- Web Worker 支持
- localStorage 可用
- 文件系统权限API
