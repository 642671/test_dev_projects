# 文件系统快照（优化快照状态）测试范围

## In-Scope

- 快照对象状态定义：正常、创建中、删除中、损坏、已过期（可选）
- 状态流转：创建中 → 正常 → 删除中 → 消失；异常路径转入创建失败 / 删除失败
- 缺陷回归：还原失败 / 成功后点击快照记录不修改快照对象状态
- 还原成功仅更新 `last_restore_time` / `restore_count`，不污染对象状态
- 损坏快照还原二次提示；还原前二次校验发现损坏时中止还原、更新状态并发送管理员告警
- 创建中 / 删除中进度展示；超过 30 分钟超时自动转失败并记录
- 状态查询超时或未知时显示“状态未知”并提示刷新
- 不同状态图标与颜色区分（正常-绿色、损坏-红色、删除中-灰色）
- 万级快照列表加载性能（含状态查询 < 2 秒）
- 任务中心：不可变更记录、字段（等级/类别/时间/用户/事件）、事件类型覆盖、成功/失败筛选与时间倒序、失败详情（错误码+推荐方案）、CSV/JSON 导出、万条记录查询与筛选 < 1 秒、最近 10000 条保留策略
- 权限场景、空状态、数据一致性（UI / API / 后台）

- 可访问后台命令行与日志

- 万级快照与万级任务记录的测试数据
