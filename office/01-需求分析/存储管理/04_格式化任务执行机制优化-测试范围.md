# 格式化任务执行机制优化 测试范围

## In-Scope

- 卷格式化：无 I/O 时立即执行
- 卷格式化：存在可中断 I/O 时中断服务后执行格式化
- 卷格式化：存在不可中断 I/O 时等待占用解除后立即执行格式化
- 卷格式化：等待场景无固定超时，占用未解除前持续等待
- 卷格式化：文件系统仅开放 BTRFS、EXT4 两种选择
- USB 格式化：无 I/O 时立即执行
- USB 格式化：存在 I/O 时中断可中断服务 / 等待不可中断服务
- USB 格式化：仅支持整个硬盘或已有分区，文件系统仅 EXT4、exFAT
- USB 格式化：开启加密时文件系统为 EXT4
- 格式化与外部客户端（SMB/FTP/NFS）读写、媒体服务扫描、容器挂载、快照/备份任务的冲突处理
- 等待状态显示、刷新、拔出重插、TNAS 重启
- 重复点击格式化、权限场景
- 格式化完成后 UI、API、后台状态一致性
- 格式化对共享文件夹、文件管理的联动影响

## Out-of-Scope

- 非格式化功能
- 具体研发技术方案实现细节
- 文件系统性能基准
- 卷格式化除 BTRFS、EXT4 之外的其它文件系统

> 模块统一为 `存储管理-格式化`，卷 / USB 格式化用例合并为一套。冲突场景详细说明见 `04_格式化任务执行机制优化-冲突场景说明.md`。

## 依赖

- TNAS / TOS 测试环境
- 已创建且可格式化的卷
- 可挂载的 USB 设备
- 可模拟文件上传、下载、复制等 I/O 的手段

## 待确认

- 等待状态文案
- 可中断与不可中断服务的判定依据
- 加密选项的适用对象（整个硬盘/已有分区）

## 占用场景初判（待后端确认 / 实测为准）

| 占用来源 | 说明 | 初判可中断性 |
| --- | --- | --- |
| 文件管理上传/下载/复制/移动 | TOS 前台发起的文件任务 | 通常可中断 |
| 外部 SMB/FTP/NFS 客户端读写 | 远程客户端保持连接并在读写 | 通常不可中断 |
| 媒体服务/缩略图扫描 | 媒体库扫描占用卷 | 视实现 |
| Docker/容器挂载卷 | 容器 bind mount 占用 | 通常不可中断 |
| 快照/备份/同步任务 | 系统任务持有卷 | 视实现 |
| USB 被系统任务或客户端占用 | 同卷场景，发生在 USB 共享 | 同上 |
