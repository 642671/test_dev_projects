## 一、需求背景与目标

### 1.1 当前状况与问题

当前 TOS 7.0 文本编辑器基于 Monaco Editor，具备基础文本编辑能力，但在处理**结构化文本**（如 CSV、TSV、日志文件、配置文件）时存在以下不足：

- 无法按行批量操作（删除、复制、移动、插入）
- 无法按列操作（选中列、批量编辑列内容）
- 无底部状态栏显示行/列统计信息
- 缺少专为行列编辑设计的快捷键
- 无操作限制和异常提示规范

**用户痛点**：运维人员编辑配置文件、数据分析师处理 CSV 日志时，需要频繁进行行列级别的批量操作，当前逐行手动编辑效率极低。

### 1.2 实现目标

| 维度 | 实现前 | 实现后 |
|------|--------|--------|
| 行操作 | 仅支持逐行编辑 | 支持选中、插入、删除、复制、剪切、移动行 |
| 列操作 | 不支持 | 支持选中、插入、删除、批量修改、合并/拆分列 |
| 快捷键 | 基础编辑快捷键 | 新增行列编辑专属快捷键（类 VS Code） |
| 底部状态栏 | 无 | 显示行序号/总行数、列序号/总列数 |

### 1.3 目标用户

- **运维人员**：批量删除指定行、移动行顺序、编辑配置文件
- **数据分析师**：按列批量添加前缀、删除空列、处理 CSV 数据
- **开发人员**：选中不连续行快速复制、按行号范围跳转、调试日志

### 1.4 用户价值

将文本编辑器升级为轻量级结构化文本处理工具，满足 CSV 日志分析、配置文件编辑等场景需求。实现后 TOS 7.0 文本编辑器将在行列编辑功能上**全面领先**群晖 DSM、绿联 UGOS、飞牛 fnOS 等同类竞品。

## 二、用户故事

- 作为**运维人员**，我希望能够**批量选中并删除多行配置内容**，以便**快速清理无效或冗余的配置项**。
- 作为**运维人员**，我希望能够**拖拽或快捷键移动行的顺序**，以便**调整配置文件中条目的优先级**。
- 作为**数据分析师**，我希望能够**使用 Alt+鼠标拖拽选中列并批量编辑**，以便**快速对 CSV 日志中的某一列进行格式化处理**。
- 作为**数据分析师**，我希望能够**在底部状态栏看到行列统计信息**，以便**快速了解当前文件的规模和数据分布**。
- 作为**开发人员**，我希望能够**使用 Ctrl+点击行号选中不连续的多行并复制**，以便**从日志中提取关键行进行分析**。
- 作为**开发人员**，我希望能够**使用 Ctrl+Z/Ctrl+Y 对所有行列操作进行撤销和重做**，以便**避免误操作带来的损失**。

## 三、功能清单与需求描述（EARS原则）

### 3.1 核心功能

#### 3.1.1 行操作功能

| 功能 | 操作方式 | 说明 |
|------|----------|------|
| 选中单行 | 点击行号 | 点击编辑器左侧行号区域，选中对应整行 |
| 选中连续多行 | 拖拽行号 | 在行号区域拖拽，选中连续的多行 |
| 选中不连续多行 | Ctrl + 点击行号 | 按住 Ctrl 键点击多个行号，选中不连续的多行 |
| 复制行 | Ctrl+C / 右键菜单 | 复制选中行的完整内容，粘贴时保留行列结构 |
| 剪切行 | Ctrl+X / 右键菜单 | 剪切选中行内容，粘贴时保留行列结构 |
| 移动行（向上） | Alt + ↑ | 将当前选中行向上移动一行位置 |
| 移动行（向下） | Alt + ↓ | 将当前选中行向下移动一行位置 |
| 移动行（拖拽） | 拖拽行号区域 | 拖拽选中行到目标位置 |
| 插入行 | 右键菜单 / 快捷键 | 在指定行上方或下方插入空行 |
| 删除行 | Delete / 右键菜单 | 删除当前选中的所有行 |

**EARS 需求表述：**

- **Ubiquitous**（始终性）：当用户在文本编辑器中打开任意文本文件时，编辑器左侧应始终显示行号区域，底部状态栏应始终显示行/列统计信息。
- **Event-driven**（事件驱动）：当用户点击行号区域时，系统应选中对应的整行内容并高亮显示。
- **Event-driven**（事件驱动）：当用户按住 Ctrl 键并点击多个行号时，系统应同时选中所有被点击的不连续行并高亮显示。
- **Event-driven**（事件驱动）：当用户按下 Alt+↑ 或 Alt+↓ 时，系统应将当前选中的行向上或向下移动一个位置，且行号自动更新。
- **Event-driven**（事件驱动）：当用户在行号区域拖拽选中行到新位置时，系统应将该行插入到目标位置并自动调整行号。
- **State-driven**（状态驱动）：当用户选中多行并执行复制/剪切操作后，系统应将选中内容保存到剪贴板，粘贴时保留原始的行列分隔结构。
- **Unwanted**（不期望行为）：当用户选中行数为 0 时，复制/剪切/删除操作应被禁用或弹出提示，防止空操作。

#### 3.1.2 列操作功能

| 功能 | 操作方式 | 说明 |
|------|----------|------|
| 选中列（垂直范围） | Alt + 鼠标拖拽 | 按住 Alt 键，鼠标拖拽选中垂直列范围 |
| 选中整列 | Ctrl + Shift + ↓ | 从当前光标位置选中整列 |
| 批量编辑列 | 列选中后输入 | 选中列后输入文本，同时在所有选中行对应列位置写入相同内容 |
| 插入列 | 右键菜单 / 快捷键 | 在指定列位置插入空列 |
| 删除列 | 右键菜单 / 快捷键 | 删除选中的列 |
| 合并列 | 右键菜单 | 将相邻多列合并为一列 |
| 拆分别 | 右键菜单 | 将一列按指定分隔符拆分为多列 |

**EARS 需求表述：**

- **Event-driven**（事件驱动）：当用户按住 Alt 键并使用鼠标拖拽时，系统应进入列选择模式，高亮显示拖拽范围内的垂直列区域。
- **Event-driven**（事件驱动）：当用户按下 Ctrl+Shift+↓ 时，系统应从当前光标位置向下选中整列内容。
- **Event-driven**（事件驱动）：当用户在列选中状态下输入字符时，系统应同时在所有选中行的对应列位置插入相同内容。
- **State-driven**（状态驱动）：当用户选中多列并执行删除操作时，系统应移除选中列并在所有行中左移后续列内容，同时更新列统计信息。
- **Optional**（可选性）：在用户执行列合并操作时，系统应提供分隔符选择（如空格、逗号、制表符等）以指定合并后的列分隔方式。
- **Unwanted**（不期望行为）：当用户尝试在单行文件中执行列操作时，系统应正常支持（列操作范围为单行），不应抛出异常。

#### 3.1.3 撤销/重做功能

| 功能 | 操作方式 | 说明 |
|------|----------|------|
| 撤销 | Ctrl + Z | 撤销上一步行列操作，恢复到操作前状态 |
| 重做 | Ctrl + Y | 重做被撤销的操作 |

**EARS 需求表述：**

- **Ubiquitous**（始终性）：所有行列操作（包括行选中编辑、列批量编辑、行列移动、删除、插入、合并拆分等）均应支持撤销和重做。
- **Event-driven**（事件驱动）：当用户执行行列操作后按下 Ctrl+Z 时，系统应撤销最近一次操作并恢复编辑器内容至操作前状态。
- **Event-driven**（事件驱动）：当用户按下 Ctrl+Y 时，系统应重做最近一次被撤销的操作。

#### 3.1.4 底部状态栏

**显示内容：**

- **行信息**：当前行序号 / 总行数（如 128 / 1024）
- **列信息**：当前列序号 / 总列数（如 3 / 8），按分隔符划分列
- **选中信息**：选中区域的行列范围（如 已选中 5行 × 3列）

**EARS 需求表述：**

- **Ubiquitous**（始终性）：底部状态栏应在编辑器底部始终可见，实时显示行/列统计信息。
- **State-driven**（状态驱动）：当用户的光标位置发生变化时，状态栏中的行序号和列序号应实时更新。
- **State-driven**（状态驱动）：当用户选中多行或多列区域时，状态栏中的选中信息应实时更新，显示选中范围的行列数。
- **Event-driven**（事件驱动）：当用户执行行列编辑操作导致总行数或总列数变化时，状态栏的总行数和总列数应自动刷新。

### 3.2 交互说明

#### 3.2.1 行号区域交互

- 鼠标悬停在行号上时，行号应呈现可交互的视觉提示（如颜色变化、光标变为手型）
- 选中的行号应有明显的高亮背景色以区分未选中的行
- 拖拽行号移动行时，应在目标位置显示插入指示线
- Ctrl+点击行号时，每次点击应切换该行的选中/取消选中状态

#### 3.2.2 列选择交互

- Alt+鼠标拖拽进入列选择模式时，光标应变为列选择光标样式
- 列选中区域应有明显的高亮背景色以区分
- 列选中后输入文本时，应在所有选中行同步显示输入内容（多光标效果）

#### 3.2.3 快捷键交互

| 功能 | 快捷键 |
|------|--------|
| 选中列（垂直范围） | Alt + 鼠标拖拽 |
| 移动行（上） | Alt + ↑ |
| 移动行（下） | Alt + ↓ |
| 撤销 | Ctrl + Z |
| 重做 | Ctrl + Y |
| 选中整列 | Ctrl + Shift + ↓ |

### 3.3 权限规则

- 文本编辑器仅对拥有文件读写权限的用户开放编辑功能
- 只读文件不允许执行行列编辑操作，所有编辑入口（快捷键、右键菜单）应禁用
- 编辑权限由 TOS 文件系统权限体系统一控制

## 四、流程与状态说明

### 4.1 业务流程图

#### 4.1.1 行操作核心流程

```
[打开文本文件]
      │
      ▼
[加载编辑器，显示行号区域和状态栏]
      │
      ├── 点击行号 ──► [选中单行，高亮行号]
      ├── 拖拽行号 ──► [选中连续多行，高亮行号范围]
      ├── Ctrl+点击 ──► [切换行选中状态，支持不连续多行]
      │
      ▼
[选中行后执行操作]
      │
      ├── 复制/剪切 ──► [保存至剪贴板，粘贴时保留行列结构]
      ├── 删除 ──► [删除选中行，行号自动更新]
      ├── 移动（Alt+↑/↓）──► [行位置交换，行号自动更新]
      └── 拖拽 ──► [插入到目标位置，行号自动更新]
      │
      ▼
[Ctrl+Z / Ctrl+Y] ──► [撤销/重做操作]
```

#### 4.1.2 列操作核心流程

```
[打开文本文件]
      │
      ▼
[加载编辑器]
      │
      ├── Alt+鼠标拖拽 ──► [进入列选择模式，高亮垂直列范围]
      └── Ctrl+Shift+↓ ──► [选中当前光标位置向下的整列]
      │
      ▼
[选中列后执行操作]
      │
      ├── 输入文本 ──► [所有选中行对应列同步写入]
      ├── 删除列 ──► [移除选中列，后续列左移]
      ├── 插入列 ──► [在指定位置插入空列]
      ├── 合并列 ──► [相邻多列合并，需选择分隔符]
      └── 拆分列 ──► [按分隔符拆分为多列]
      │
      ▼
[Ctrl+Z / Ctrl+Y] ──► [撤销/重做操作]
```

### 4.2 状态流转

#### 4.2.1 行选中状态

```
[未选中] ──点击行号──► [单行选中]
[未选中] ──拖拽行号──► [连续多行选中]
[未选中] ──Ctrl+点击──► [不连续多行选中]
[单行选中] ──Ctrl+点击另一行──► [不连续多行选中]
[连续多行选中] ──Ctrl+点击某行──► [切换该行选中状态]
[任意选中] ──点击编辑区域──► [取消选中，返回未选中]
```

#### 4.2.2 列选中状态

```
[未选中] ──Alt+鼠标拖拽──► [列区域选中]
[未选中] ──Ctrl+Shift+↓──► [整列选中]
[列选中] ──输入文本──► [批量编辑状态] ──Esc──► [取消选中]
[列选中] ──点击编辑区域──► [取消选中，返回未选中]
```

### 4.3 边界场景与异常处理

#### 4.3.1 操作限制

| 限制项 | 上限值 | 触发时机 | 用户操作 |
|--------|--------|----------|----------|
| 超时阈值 | 30 秒 | 操作执行中 | 显示 Loading + 提示，继续等待 |
| 内存不足 | 待定 | 编辑器内存占用超过限制 | 提示保存并建议关闭其他标签页 |

#### 4.3.2 边界场景处理

| 场景 | 处理方式 |
|------|----------|
| 空文件（0行0列） | 行号区域为空，状态栏显示 `0 / 0`，行列编辑操作入口禁用 |
| 单行文件的行操作 | 移动行功能禁用（仅一行无可移动方向），其他操作正常 |
| 单行文件的列操作 | 列操作范围限制在当前行内，列选中、编辑等正常支持 |
| 选中最后一行向下移动 | 不执行移动，可选：给出轻微视觉提示（如行号闪烁） |
| 选中第一行向上移动 | 同上，不执行移动 |
| 粘贴内容行数超过当前文件行数 | 正常粘贴，文件行数自动增加 |
| 列选中范围超出某行实际列数 | 超出部分视为空列处理，批量编辑时空列也写入内容 |
| 大文件操作（>10000行） | 显示处理进度（Loading），超时 30 秒后提示用户 |
| 撤销栈溢出 | 限制撤销栈深度（如 100 步），超出时移除最早的记录 |
| 并发编辑冲突 | 当前版本为单用户编辑，不考虑并发冲突 |

#### 4.3.3 异常提示文案

| 异常类型 | 触发条件 | 提示文案 |
|----------|----------|----------|
| 内存不足 | 编辑器内存占用超过限制 | 内存不足，请保存当前文件并关闭其他标签页后重试。 |
| 操作超时 | 操作执行超过 30 秒 | 当前操作耗时较长，请稍候...（带 Loading 动画） |
| 只读文件 | 尝试编辑只读文件 | 当前文件为只读模式，无法执行编辑操作。 |
| 文件过大 | 打开文件超过推荐大小 | 文件较大，编辑性能可能受到影响，建议关闭其他标签页。 |

## 六、验收标准

### 6.1 功能验收

| 分类 | 验收项 | 验收标准 |
|------|--------|----------|
| 行编辑 | 选中单行/连续多行/不连续多行 | 点击行号选中单行，拖拽选中连续多行，Ctrl+点击选中不连续多行，高亮正确 |
| 行编辑 | 插入/删除/复制/移动行 | 操作后行号自动更新，内容正确，粘贴时保留行列结构 |
| 行编辑 | 拖拽移动行 | 拖拽行号到目标位置，行插入正确，行号更新正确 |
| 列编辑 | 选中列（Alt+拖拽） | Alt+鼠标拖拽正确选中垂直列范围，高亮正确 |
| 列编辑 | 选中整列（Ctrl+Shift+↓） | 从光标位置向下正确选中整列 |
| 列编辑 | 批量编辑列 | 列选中后输入，所有选中行对应列同步写入相同内容 |
| 列编辑 | 插入/删除列 | 操作后列号自动更新，后续列正确移位 |
| 列编辑 | 合并/拆分列 | 合并时提供分隔符选择，拆分按分隔符正确执行 |
| 快捷键 | 所有快捷键生效 | Alt+↑/↓ 移动行，Ctrl+Z 撤销，Ctrl+Y 重做，无快捷键冲突 |
| 底部状态栏 | 行/列统计显示 | 实时更新光标所在行列号，选中区域信息正确 |
