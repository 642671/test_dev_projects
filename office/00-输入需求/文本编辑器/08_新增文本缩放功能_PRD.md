## 一、需求背景与目标

### 1.1 当前状况与问题

当前 TOS 7.0 文本编辑器已实现基础编辑功能，但存在以下不足：

- 不支持视图缩放功能，用户无法调整编辑器内容的显示大小
- 高分辨率屏幕下文本显示过小，阅读困难
- 投影或演示场景下无法临时放大内容
- 长时间编辑时无法通过缩放缓解视觉疲劳
- 与群晖、绿联等竞品相比，缺少基础的缩放体验

### 1.2 实现目标

| 维度 | 实现前 | 实现后 |
|------|--------|--------|
| 缩放功能 | 不支持 | 支持调整编辑器视图缩放比例 |
| 缩放范围 | — | **50% - 200%** |
| 缩放方式 | — | 下拉菜单选择 / Ctrl+滚轮 |
| 默认缩放 | — | 100% |
| 缩放记忆 | — | 支持记住用户的缩放设置 |
| 竞品对齐 | 功能缺失 | 对齐绿联、覆盖群晖核心体验 |

### 1.3 目标用户

- **高分辨率屏幕用户**：使用 4K/5K 高分屏，需要放大编辑器内容以获得舒适的阅读体验
- **演示场景用户**：在团队会议、代码评审等场景中需要临时放大内容的用户
- **长时间编辑用户**：长时间编写文档，需要通过适度放大来缓解视觉疲劳的用户
- **低视力用户**：有视觉辅助需求，需要较大缩放比例的用户

### 1.4 用户价值

- **提升阅读舒适度**：用户可根据屏幕分辨率和自身视力情况自由调整显示比例，减少视觉疲劳
- **增强演示体验**：会议/演示场景下可一键放大内容，提升信息传达效率
- **补足竞品短板**：覆盖绿联核心体验、对齐群晖缩放能力，消除产品功能缺失
- **个性化编辑体验**：缩放记忆功能让用户无需每次手动调整，打开即用

## 三、功能清单与需求描述（EARS原则）

### 3.1 核心功能

#### F1：缩放范围与预设刻度

| 参数 | 规格说明 |
|------|----------|
| 最小缩放 | 50% |
| 最大缩放 | 200% |
| 默认缩放 | 100% |
| 步长 | 通过 Ctrl+滚轮按预设档位切换 |
| 预设刻度 | 7 档：50%、70%、85%、100%、125%、150%、200% |

**预设刻度说明**：

| 刻度 | 使用场景 |
|------|----------|
| 50% | 缩略视图，快速浏览大文档结构 |
| 70% | 轻度缩小，适合同时查看多文件 |
| 85% | 适中缩小，接近默认但稍小 |
| 100% | 默认视图，1:1 显示 |
| 125% | 舒适放大，长时间编辑推荐 |
| 150% | 显著放大，适合演示或视觉辅助 |
| 200% | 最大放大，适合细节查看或低视力用户 |

**EARS 需求表述**：

- **[Ubiquitous]** 编辑器在任何时候都应支持 50% 到 200% 之间的视图缩放。
- **[Ubiquitous]** 缩放预设刻度固定为 7 档（50%、70%、85%、100%、125%、150%、200%），不可由用户自定义。
- **[State-driven]** 当用户首次打开编辑器或未设置过缩放值时，编辑器应以 100% 默认缩放比例渲染内容。
- **[Event-driven]** 当用户通过下拉菜单选择预设刻度时，编辑器应立即以所选比例重新渲染视图。

#### F2：缩放方式 — 下拉菜单

| 方式 | 规格说明 |
|------|----------|
| 下拉菜单选择 | 点击底部状态栏缩放区域，弹出缩放菜单，选择预设刻度 |

**缩放菜单样式（示意）**：

```
│ 缩放比例          │
│                    │
│ ○ 50%             │
│ ○ 70%             │
│ ○ 85%             │
│ ● 100%            │
│ ○ 125%            │
│ ○ 150%            │
│ ○ 200%            │
```

> 注：菜单布局可根据 UI 设计优化，此图仅为示意。当前选中项以圆点标记。

**EARS 需求表述**：

- **[Event-driven]** 当用户点击底部状态栏缩放区域时，系统应弹出包含 7 档预设刻度的缩放菜单。
- **[Event-driven]** 当用户在缩放菜单中选择一个预设刻度时，菜单应关闭，当前选中刻度应以视觉标记（如圆点/高亮）标识。
- **[State-driven]** 底部状态栏缩放区域应始终显示当前缩放比例（如"缩放 100%"）。

#### F3：缩放方式 — 快捷键

| 快捷键 | 功能 |
|--------|------|
| Ctrl + 鼠标滚轮向上 | 放大切档 |
| Ctrl + 鼠标滚轮向下 | 缩小切档 |

**EARS 需求表述**：

- **[Event-driven]** 当用户在编辑器区域内按住 Ctrl 并向上滚动鼠标滚轮时，系统应将缩放比例切换至下一个更大的预设档位。
- **[Event-driven]** 当用户在编辑器区域内按住 Ctrl 并向下滚动鼠标滚轮时，系统应将缩放比例切换至下一个更小的预设档位。
- **[Unwanted]** 当缩放已达到 200% 最大值时，Ctrl+滚轮向上操作不应再继续放大。
- **[Unwanted]** 当缩放已达到 50% 最小值时，Ctrl+滚轮向下操作不应再继续缩小。
- **[Ubiquitous]** 快捷键缩放应仅在编辑器区域获得焦点时生效，避免与其他应用的 Ctrl+滚轮快捷键冲突。

#### F4：缩放记忆

| 功能点 | 规格说明 |
|--------|----------|
| 持久化存储 | 缩放设置保存到本地浏览器存储（如 localStorage），关闭编辑器后重新打开保持上次缩放 |
| 默认行为 | 首次打开编辑器或未设置过缩放值时，默认缩放为 100% |

**EARS 需求表述**：

- **[Event-driven]** 当用户每次调整缩放比例后，系统应将当前缩放值持久化保存到本地浏览器存储。
- **[State-driven]** 当用户重新打开编辑器时，系统应从本地存储读取上次保存的缩放值并应用。
- **[State-driven]** 当本地存储中不存在缩放值（首次使用或缓存被清除）时，系统应使用 100% 默认缩放。
- **[Unwanted]** 当缩放记忆加载失败（如存储数据损坏）时，系统应静默回退到 100% 默认缩放，并可在控制台输出调试信息。

#### F5：缩放效果

| 功能点 | 规格说明 |
|--------|----------|
| 实时生效 | 调整缩放比例后，编辑器内容立即按新比例渲染 |
| 影响范围 | 缩放仅影响编辑器**视图显示**，不改变实际字体大小和文件内容 |
| 行号同步 | 行号区域同步缩放，保持与编辑内容比例一致 |
| 语法高亮 | 语法高亮颜色和样式不受缩放影响 |
| 平滑过渡 | 缩放过程应有平滑的视觉效果，避免闪烁或跳动 |

**EARS 需求表述**：

- **[Ubiquitous]** 缩放应仅影响编辑器内容的视觉呈现（CSS transform 或 font-size 缩放），不得修改文档的实际字体大小、样式或文件内容。
- **[Ubiquitous]** 行号区域（gutter）应与编辑区域保持同步缩放，确保行号与对应代码行始终对齐。
- **[Ubiquitous]** 语法高亮的颜色、字体样式（加粗/斜体）在缩放过程中应保持不变。
- **[Optional]** 缩放切换时，编辑器应提供平滑的视觉过渡动画，避免内容闪烁或跳动。

### 3.2 交互说明

#### 入口位置

编辑器底部状态栏，与行号、编码、语言选择等状态信息并列显示。

**底部状态栏布局示意**：

```
行：128 列：32 │ 编码 UTF-8 ▼ │ 语言 Python ▼ │ 缩放 100% ▼ │
```

#### 交互流程

1. **查看当前缩放**：底部状态栏显示"缩放 XXX%"
2. **下拉菜单调整**：
   - 点击"缩放 XXX%"区域 → 弹出 7 档缩放菜单
   - 当前选中项高亮显示（带圆点标记）
   - 点击目标档位 → 菜单关闭，缩放立即生效，状态栏更新
3. **快捷键调整**：
   - 编辑器获得焦点
   - Ctrl + 鼠标滚轮向上 → 放大一档
   - Ctrl + 鼠标滚轮向下 → 缩小一档
   - 状态栏同步更新

#### 视觉反馈

- 缩放切换时，编辑器内容应有平滑过渡动画（建议使用 CSS transition，时长 150-200ms）
- 状态栏缩放数值实时更新
- 达到边界值（50% 或 200%）时，Ctrl+滚轮操作无效果，不产生额外提示

### 3.3 权限规则

- 所有用户均可使用缩放功能，无权限限制
- 缩放设置为用户级别，不同用户的缩放偏好独立存储
- 缩放设置不影响其他用户的编辑器视图

## 四、流程与状态说明

### 4.1 业务流程图

```
                        用户触发缩放
                             │
                             ↓
                    判断缩放方式
                    ┌──────┴──────┐
                    │             │
              下拉菜单选择    Ctrl+滚轮
                    │             │
                    ↓             ↓
            获取预设刻度值   当前值 ± 下一档值
                            检查边界限制
                    │             │
                    └──────┬──────┘
                           ↓
                    应用缩放比例
                           │
                           ↓
                 编辑器视图重新渲染
                  ┌──────┼──────┐
                  │      │      │
                  ↓      ↓      ↓
            编辑内容   行号区域   语法高亮
            缩放       同步缩放   保持不变
                  │      │      │
                  └──────┼──────┘
                           ↓
                 保存缩放值到浏览器缓存
                           │
                           ↓
                 更新状态栏缩放显示
                           │
                           ↓
                         完成
```

### 4.2 状态流转

缩放状态为一维数值状态，在预设的 7 个档位之间切换：

```
50% ←→ 70% ←→ 85% ←→ 100% ←→ 125% ←→ 150% ←→ 200%
```

- **向上滚动/选择更大刻度**：沿箭头方向向右移动一档
- **向下滚动/选择更小刻度**：沿箭头方向向左移动一档
- **到达 50% 边界**：不可再向左（缩小）移动
- **到达 200% 边界**：不可再向右（放大）移动

### 4.3 边界场景与异常处理

| 异常类型 | 处理方式 | 提示文案/行为 |
|----------|----------|---------------|
| 缩放记忆加载失败 | 静默回退，使用默认 100% 缩放 | 控制台输出调试信息，不对用户展示错误 |
| 缩放比例保存失败 | 静默失败，不影响当前缩放效果 | 控制台输出调试信息，不对用户展示错误 |
| 浏览器不支持 localStorage | 缩放功能正常使用，但不保存记忆，每次打开恢复 100% | 控制台输出调试信息 |
| 极低分辨率屏幕（如 800x600） | 编辑器最小宽度保证可用，缩放功能不受影响 | 无特殊提示 |
| 编辑器失去焦点时 Ctrl+滚轮 | 不触发缩放，由浏览器默认行为处理 | 无操作 |
| 下拉菜单打开时 Ctrl+滚轮 | 菜单关闭，缩放按快捷键逻辑切换 | 正常交互 |
| 连续快速滚轮操作 | 每次滚轮事件触发一次档位切换，按预设档位顺序执行 | 正常切换 |
| 用户清除浏览器缓存 | 下次打开编辑器恢复 100% 默认缩放 | 无提示 |
| 浏览器隐私模式 | 缩放记忆在会话内有效，关闭浏览器后丢失 | 与正常模式行为一致 |

### 6.2 性能验收

| 验收项 | 验收标准 |
|--------|----------|
| 缩放响应时间 | 缩放操作触发后，编辑器内容在 200ms 内完成重新渲染 |
| 缩放流畅度 | 连续快速切换缩放档位（通过滚轮）时，无卡顿、无白屏、无闪烁 |

| 内存占用 | 缩放操作不应导致浏览器内存显著增长（增量 < 10MB） |
| 动画帧率 | 缩放过渡动画帧率 ≥ 30fps |

| 触摸设备 | 触摸屏设备上双指捏合缩放行为与 Ctrl+滚轮逻辑一致（可选） |

### 7.2 参考资料

- **UI 设计图档**: [MasterGo 设计稿](https://mastergo.com/file/191459527527705?shareId=191459527527705&page_id=M)
- **竞品参考 — 群晖 Synology Office**:
  - 缩放范围: 20% - 200%（连续可输入任意值）
  - 支持 Ctrl+鼠标滚轮快捷缩放
  - 支持"记住我的设置"缩放记忆
- **竞品参考 — 绿联 UGOS Pro**:
  - 缩放范围: 50% - 150%
  - 预设 5 档刻度（50/80/100/120/150）
  - 支持 Ctrl+鼠标滚轮快捷缩放
  - 不支持缩放记忆

**竞品对比总结**：

群晖支持更灵活的缩放范围和记忆功能；绿联仅支持预设刻度。TOS 7.0 结合两者优点：覆盖绿联核心刻度 + 扩展至 200% + 缩放记忆。

### 7.3 待确认问题

1. **技术实现方案**：由研发团队填写具体技术方案（CSS Transform 缩放 vs 修改编辑器字体大小）
2. **多标签页同步**：用户同时打开多个编辑器标签页时，缩放设置是独立存储还是全局共享？
3. **移动端适配**：触摸设备上的双指缩放是否作为 v2.0 范围？如需实现，交互方式是否与桌面端一致？
4. **国际化**：下拉菜单中的"缩放"文案是否需要多语言支持？
5. **无障碍访问**：是否支持键盘快捷键（如 Ctrl++ / Ctrl+-）进行缩放？是否需要 ARIA 标签？
6. **UI 设计终稿**：缩放菜单的最终 UI 样式（圆角、间距、阴影、选中态颜色）需与设计师确认
7. **缩放重置功能**：是否需要在菜单中增加"重置为 100%"选项？
8. **埋点方案审批**：5.2 节中的埋点事件方案需与数据团队确认后实施
