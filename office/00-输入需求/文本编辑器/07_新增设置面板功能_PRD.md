## 一、需求背景与目标

### 1.1 当前状况与问题

当前 TOS 7.0 文本编辑器已实现基础编辑功能，但存在以下不足：

- 无独立的设置面板，用户无法自定义编辑体验
- 无法控制隐藏字符（空格、制表符）的显示
- 无缩进参考线，代码对齐困难
- 无法自定义行号显示
- 无高亮当前行功能
- 无高亮所选词功能
- 无显示模式切换（常规模式 / 暗黑模式）
- 自动换行策略单一，无法自定义换行列数
- 无自动保存功能

### 1.2 实现目标

| 维度 | 实现前 | 实现后 |
|------|--------|--------|
| 设置入口 | 无 | 编辑器顶部菜单栏 → 设置 / 偏好设置 |
| 隐藏字符显示 | 不支持 | 支持显示空格、制表符等隐藏字符 |
| 缩进参考线 | 不支持 | 支持显示缩进参考线 |
| 行号显示 | 基础显示 | 支持显示/隐藏行号 |
| 高亮当前行 | 不支持 | 支持高亮当前光标所在行 |
| 高亮所选词 | 不支持 | 支持高亮当前选中的词语 |
| 自动换行 | 单一策略 | 支持按窗口宽度换行 / 按自定义列数换行 |
| 自动保存 | 不支持 | 支持自动保存，可设置保存间隔 |

### 1.3 目标用户

- **开发者**：编写代码时需要通过缩进参考线、隐藏字符显示等辅助功能提升编码效率
- **运维人员**：编辑配置文件时需要识别不可见字符，排查格式错误
- **文档编辑者**：需要自动保存功能防止意外丢失内容
- **所有文本编辑器用户**：期望自定义编辑器显示和编辑体验

### 1.4 用户价值

- **提升编辑效率**：通过缩进参考线、高亮当前行等功能，降低代码/文本对齐和定位成本
- **减少错误**：显示隐藏字符，帮助用户快速发现和修正格式问题
- **个性化体验**：支持显示模式切换和多种显示选项，满足不同用户偏好
- **数据安全保障**：自动保存功能降低因意外关闭导致的内容丢失风险
- **竞品对齐**：补足与群晖 DSM、绿联 UGOS 在编辑器设置功能上的差距

## 三、功能清单与需求描述（EARS原则）

### 3.1 核心功能

#### 3.1.1 设置面板入口

- **[Ubiquitous]** 设置入口应始终位于编辑器顶部菜单栏中，菜单项名称为「设置」或「偏好设置」
- **[State-driven]** 当用户点击设置菜单项时，系统应弹出设置面板弹窗
- **[State-driven]** 当设置面板处于打开状态时，编辑器主体区域应处于不可编辑状态（模态弹窗）

#### 3.1.2 设置面板布局

- **[Ubiquitous]** 设置面板应包含「显示」和「编辑」两个标签页
- **[Ubiquitous]** 每个标签页应包含对应分类的设置项，使用开关、下拉选择、数字输入等控件
- **[Ubiquitous]** 面板底部应包含「恢复默认设置」按钮和「关闭」按钮
- **[Event-driven]** 当用户点击「恢复默认设置」按钮时，系统应将所有设置项恢复为出厂默认值
- **[Event-driven]** 当用户修改任何设置项并关闭面板时，修改应立即生效并持久化

#### 3.1.3 显示模式切换

- **[Ubiquitous]** 系统应支持「常规模式（亮色主题）」和「暗黑模式（暗色主题）」两种显示模式
- **[State-driven]** 当显示模式设置为常规模式时，编辑器背景应为白色/浅色，文字为深色，适合日间使用
- **[State-driven]** 当显示模式设置为暗黑模式时，编辑器背景应为深色，文字为浅色，适合夜间或弱光环境使用
- **[Ubiquitous]** 默认显示模式为「常规模式」
- **[Event-driven]** 当用户切换显示模式时，编辑器主题和所有语法高亮颜色应实时适配新主题
- **[Optional]** 当系统支持时，编辑器可跟随操作系统主题设置自动同步

#### 3.1.4 显示隐藏字符

- **[State-driven]** 当「显示隐藏字符」开关开启时，空格应显示为「·」点号，制表符应显示为「→」箭头，换行符应显示为「¶」符号
- **[State-driven]** 当「显示隐藏字符」开关关闭时，编辑器恢复正常显示，不显示任何隐藏字符标记
- **[Ubiquitous]** 该功能默认关闭
- **[Event-driven]** 当用户切换开关状态时，编辑器内容应立即重新渲染以反映变更

#### 3.1.5 显示缩进参考线

- **[State-driven]** 当「显示缩进参考线」开关开启时，在代码缩进位置应显示垂直参考线，便于对齐代码块
- **[State-driven]** 当「显示缩进参考线」开关关闭时，不显示任何参考线
- **[Ubiquitous]** 该功能默认关闭
- **[Event-driven]** 当用户切换开关状态时，参考线应立即显示或隐藏

#### 3.1.6 显示行号

- **[State-driven]** 当「显示行号」开关开启时，编辑器左侧应显示行号
- **[State-driven]** 当「显示行号」开关��闭时，编辑器左侧不显示行号
- **[Ubiquitous]** 该功能默认开启
- **[Event-driven]** 当用户切换开关状态时，行号区域应立即显示或隐藏，编辑器内容区域宽度相应调整

#### 3.1.7 高亮当前行

- **[State-driven]** 当「高亮当前行」开关开启时，光标所在行应显示背景高亮
- **[State-driven]** 当「高亮当前行」开关关闭时，光标所在行无特殊高亮
- **[Ubiquitous]** 该功能默认开启
- **[Event-driven]** 当用户移动光标到不同行时，高亮应跟随光标位置实时移动

#### 3.1.8 高亮所选词

- **[State-driven]** 当「高亮所选词」开关开启时，用户选中某词语后，文档中所有相同词语应高亮显示
- **[State-driven]** 当「高亮所选词」开关关闭时，选中词语无高亮效果
- **[Ubiquitous]** 该功能默认关闭
- **[Event-driven]** 当用户选中不同词语时，高亮应实时更新到新选中的词语

#### 3.1.9 自动换行

- **[Ubiquitous]** 系统应提供「按窗口宽度换行」和「按自定义列数换行」两种自动换行策略
- **[Ubiquitous]** 默认换行策略为「按窗口宽度换行」
- **[State-driven]** 当选择「按窗口宽度换行」时，行内容超过编辑器窗口可视宽度时自动换行，换行后文本所在行数不变
- **[State-driven]** 当选择「按自定义列数换行」时，行内容超过用户指定列数时自动换行，列数范围为 20-200，默认值为 80
- **[Event-driven]** 当用户切换换行策略或修改列数时，编辑器内容应立即重新渲染
- **[Unwanted]** 如果用户输入的列数超出 20-200 范围，系统应拒绝该输入并恢复上次有效值，提示「列数范围为 20-200，请输入有效值。」

#### 3.1.10 自动保存

- **[State-driven]** 当「启用自动保存」开关开启时，编辑器应按设定间隔自动保存当前编辑的文件
- **[Ubiquitous]** 该功能默认关闭
- **[Ubiquitous]** 默认保存间隔为 3 秒
- **[Ubiquitous]** 保存间隔可设置范围为 10-3600 秒
- **[Event-driven]** 当用户停止输入后，系统开始计时；计时到达设定间隔后自动执行保存
- **[Ubiquitous]** 自动保存时不显示保存对话框
- **[State-driven]** 当文件为新建文件（未保存路径）时，自动保存不生效，等待用户手动另存为指定路径
- **[State-driven]** 当文件为只读文件时，不执行自动保存
- **[State-driven]** 当文件为锁定文件时，不执行自动保存
- **[Unwanted]** 如果自动保存因磁盘空间不足而失败，系统应停止自动保存并提示「自动保存失败！文件所在位置可用空间不足。」
- **[Unwanted]** 如果自动保存因权限不足而失败，系统应停止自动保存并提示「自动保存失败！您的账户权限不足。」

#### 3.1.11 设置持久化

- **[Ubiquitous]** 所有设置项应保存到本地浏览器存储（localStorage）
- **[State-driven]** 当用户关闭编辑器后重新打开时，所有设置应保持上次关闭前的状态
- **[State-driven]** 当用户首次打开编辑器时，所有设置项应使用出厂默认值
- **[Event-driven]** 当用户点击「恢复默认设置」时，所有设置项应立即恢复为默认值并持久化存储

### 3.2 交互说明

#### 3.2.1 设置面板交互流程

1. 用户点击编辑器顶部菜单栏「设置」
2. 系统弹出设置面板模态窗口，默认展示「显示」标签页
3. 用户可在「显示」和「编辑」标签页间切换
4. 用户修改设置项，变更实时预览（无需点击保存按钮）
5. 用户点击面板外部区域或「关闭」按钮，面板关闭，设置持久化存储

#### 3.2.2 自动换行设置流程

```
用户打开设置面板
  ↓
选择「编辑」标签页
  ↓
选择自动换行策略
  ├─ 按窗口宽度换行 → 编辑器以窗口宽度为换行边界
  └─ 按自定义列数换行 → 弹出列数输入框，用户输入列数（20-200）
  ↓
点击关闭面板
  ↓
编辑器立即按新策略重新渲染换行
  ↓
完成
```

#### 3.2.3 自动保存流程

```
用户开启自动保存
  ↓
设置保存间隔（默认 3 秒，可设置 10-3600 秒）
  ↓
用户开始编辑文件
  ↓
用户停止输入，启动计时器
  ↓
计时器到达设定间隔
  ↓
检查文件状态
  ├─ 新建文件（未保存路径） → 跳过自动保存，等待手动保存
  ├─ 只读文件 → 跳过自动保存
  ├─ 锁定文件 → 跳过自动保存
  └─ 正常文件 → 执行自动保存
  ↓
保存完成，等待下一次编辑
  ↓
完成
```

## 四、流程与状态说明

### 4.1 业务流程图（用文字描述）

#### 4.1.1 设置面板主流程

1. **入口触发**：用户点击编辑器顶部菜单栏「设置」菜单项
2. **面板展示**：弹出设置面板模态窗口，默认展示「显示」标签页
3. **标签切换**：用户可在「显示」标签页（显示模式、隐藏字符、缩进参考线、行号、当前行高亮、所选词高亮）和「编辑」标签页（自动换行策略、自动保存）之间切换
4. **设置修改**：用户通过开关控件、下拉选择控件或数字输入控件修改设置项
5. **实时生效**：除列数输入等需确认的控件外，大部分开关切换应立即在编辑器中实时预览效果
6. **面板关闭**：用户点击关闭按钮或面板外区域，面板关闭，设置持久化存储

#### 4.1.2 显示模式切换流程

1. 用户在「显示」标签页找到「显示模式」设置项
2. 选择「常规模式」或「暗黑模式」
3. 编辑器主题立即切换，语法高亮颜色同步适配
4. 设置持久化到本地存储

#### 4.1.3 自动保存异常处理流程

1. 自动保存触发 → 执行保存操作
2. 保存失败 → 判断失败原因
   - 磁盘空间不足 → 停止自动保存，提示用户，等待用户手动操作
   - 权限不足 → 停止自动保存，提示用户，等待用户手动操作
3. 用户手动保存成功 → 自动保存功能可重新启用

### 4.2 状态流转

#### 4.2.1 设置面板状态

| 状态 | 说明 | 触发条件 |
|------|------|----------|
| 关闭 | 设置面板不可见 | 默认状态 / 用户点击关闭 |
| 打开-显示标签页 | 展示显示相关设置 | 用户打开设置面板（默认） |
| 打开-编辑标签页 | 展示编辑相关设置 | 用户切换到编辑标签页 |

#### 4.2.2 自动保存状态

| 状态 | 说明 | 触发条件 |
|------|------|----------|
| 关闭 | 自动保存功能未启用 | 默认状态 / 用户关闭开关 |
| 待机 | 已启用但用户正在输入 | 用户启用自动保存后开始输入 |
| 计时中 | 用户停止输入，等待保存 | 用户停止输入 |
| 保存中 | 正在执行自动保存 | 计时器到达设定间隔 |
| 已保存 | 保存成功，等待下次触发 | 保存操作完成 |
| 保存失败 | 保存操作失败 | 磁盘空间不足 / 权限不足 |
| 跳过 | 当前文件不满足保存条件 | 新建文件 / 只读文件 / 锁定文件 |

#### 4.2.3 换行策略状态

| 状态 | 说明 |
|------|------|
| 按窗口宽度 | 默认策略，行内容超过窗口宽度时自动换行 |
| 按自定义列数 | 用户自定义列数（20-200），行内容超过指定列数时换行 |

### 4.3 边界场景与异常处理

| 异常类型 | 处理方式 | 提示文案 | 恢复方式 |
|----------|----------|----------|----------|
| 自动换行列数超出范围 | 输入时校验，超出范围时恢复上次有效值 | 列数范围为 20-200，请输入有效值。 | 用户重新输入有效值 |
| 自动保存失败（磁盘空间不足） | 停止自动保存，提示用户手动保存 | 自动保存失败！文件所在位置可用空间不足。 | 用户清理空间后手动保存，重新启用自动保存 |
| 自动保存失败（权限不足） | 停止自动保存，提示用户手动保存 | 自动保存失败！您的账户权限不足。 | 用户检查权限后手动保存 |
| 新建文件触发自动保存 | 跳过自动保存，不提示 | 无提示 | 用户手动另存为后，自动保存生效 |
| 只读文件触发自动保存 | 跳过自动保存，不提示 | 无提示 | N/A |
| 锁定文件触发自动保存 | 跳过自动保存，不提示 | 无提示 | N/A |
| localStorage 不可用 | 设置变更不持久化，使用默认值 | 无提示（静默降级） | 用户检查浏览器设置 |
| 编辑器窗口大小变化 | 按窗口宽度换行时，换行位置实时跟随窗口宽度调整 | 无提示 | N/A |
| 超长行内容 | 正常按换行策略处理，不影响编辑器性能 | 无提示 | N/A |
| 连续快速切换设置 | 以最后一次操作为准，防抖处理 | 无提示 | N/A |

## 六、验收标准

### 6.1 功能验收

| 分类 | 验收项 | 验收标准 |
|------|--------|----------|
| 显示设置 | 显示模式切换 | 切换常规模式/暗黑模式后，编辑器主题实时生效，语法高亮颜色适配 |
| 显示设置 | 显示隐藏字符 | 开启后空格显示「·」、制表符显示「→」、换行符显示「¶」；关闭后恢复正常 |
| 显示设置 | 显示缩进参考线 | 开启后在缩进位置显示垂直参考线，参考线对齐缩进层级 |
| 显示设置 | 显示行号 | 开启后左侧显示行号，关闭后隐藏，行号与实际行数对应正确 |
| 显示设置 | 高亮当前行 | 开启后光标所在行有背景高亮，光标移动时高亮跟随 |
| 显示设置 | 高亮所选词 | 选中词语后，文档中所有相同词语高亮显示，区分大小写 |
| 自动换行 | 按窗口宽度换行 | 内容超过窗口宽度时自动换行，调整窗口大小时换行位置实时更新 |
| 自动换行 | 按自定义列数换行 | 内容超过设定列数时自动换行，列数可调节（20-200），输入超出范围时提示并拒绝 |
| 自动保存 | 启用自动保存 | 按设定间隔自动保存文件，保存时无弹窗提示 |
| 自动保存 | 保存间隔 | 支持设置 10-3600 秒间隔，默认 3 秒 |
| 自动保存 | 新建文件处理 | 未保存路径的文件不触发自动保存 |
| 自动保存 | 只读文件处理 | 只读文件不触发自动保存 |
| 自动保存 | 锁定文件处理 | 锁定文件不触发自动保存 |
| 自动保存 | 保存失败处理 | 空间不足或权限不足时停止自动保存并给出明确提示 |
| 持久化 | 设置记忆 | 关闭编辑器后重新打开，设置保持上次状态 |
| 持久化 | 恢复默认 | 点击「恢复默认设置」后所有选项恢复默认值 |
| 持久化 | 首次使用 | 首次打开编辑器时所有设置项使用出厂默认值 |

### 6.2 性能验收

| 验收项 | 验收标准 |
|--------|----------|
| 设置面板打开速度 | 点击设置菜单后，面板应在 300ms 内弹出并完成渲染 |
| 显示模式切换速度 | 切换常规/暗黑模式后，编辑器主题应在 200ms 内完成切换 |
| 开关切换响应速度 | 切换任意显示开关后，编辑器应在 100ms 内完成重新渲染 |
| 自动换行重新渲染 | 切换换行策略或修改列数后，编辑器应在 500ms 内完成重新渲染 |
| 自动保存对编辑的影响 | 自动保存操作不应阻塞用户编辑，保存过程对用户无感知 |
| 大文件处理 | 在 10MB 以上文件中切换显示设置时，渲染时间不超过 2 秒 |
| 内存占用 | 开启所有显示设置后，编辑器内存增量不超过 50MB |

### 6.3 兼容性验收

| 验收项 | 验收标准 |
|--------|----------|
| 浏览器兼容 | 支持 Chrome 90+、Firefox 90+、Edge 90+、Safari 14+ |
| localStorage 降级 | 当浏览器不支持或不启用 localStorage 时，编辑器正常使用但设置不持久化 |
| 多标签页 | 同一浏览器多个标签页打开编辑器时，设置互不影响 |
| 不同分辨率 | 支持 1280x720 及以上分辨率正常显示设置面板 |
| 键盘操作 | 设置面板支持 Tab 键切换焦点、Enter 键确认、Esc 键关闭面板 |
