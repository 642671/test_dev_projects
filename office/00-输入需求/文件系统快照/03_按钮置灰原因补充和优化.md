**目前是什么状况？**

当前快照管理功能在操作权限控制方面存在以下问题：

1. **操作权限边界模糊**：不同状态（正常、创建中、删除中、损毁）的快照，哪些操作允许、哪些不允许，缺乏统一的权限矩阵定义
2. **损毁快照无法清理**：快照进入“损毁”状态后用户无法执行任何操作（包括删除），导致异常快照永久占用存储空间
3. **全局任务冲突**：系统正在执行创建/删除快照任务时，“拍快照”按钮仍可点击，可能导致任务冲突
4. **缺乏明确提示**：用户面对灰色按钮时仅知道不可操作，不了解具体原因
5. **“清除”范围不明确**：清除所有快照时，对创建中/删除中快照的处理方式缺乏明确定义

**通过实现需求达到什么目的？**



- **规范操作权限**：基于快照状态矩阵精确控制操作按钮的可用性，避免用户执行不允许的操作
- **提供损毁快照清理出口**：允许删除损毁快照，释放被异常占用的存储空间
- **避免任务冲突**：系统任务进行时自动禁用“拍快照”和“清除”按钮，防止并发冲突
- **提升用户体验**：所有不可用按钮提供明确的状态原因提示，降低用户困惑
- **明确定义“清除”范围**：存在处理中快照时禁止清除，保障批量操作的数据一致性

**详细功能要求是什么？**

#### 一、快照状态定义

| 状态       | 说明                         | 典型场景                           |
| :--------- | :--------------------------- | :--------------------------------- |
| **正常**   | 快照完整可用，可执行所有操作 | 快照创建完成，数据完整             |
| **创建中** | 快照正在创建过程中           | 用户刚触发拍快照，后台任务正在执行 |
| **删除中** | 快照正在被删除               | 用户触发删除，后台任务正在执行     |
| **损毁**   | 快照数据不完整或校验失败     | 底层存储异常或快照元数据损坏       |

#### 二、快照操作权限矩阵

| 快照状态   | 拍快照* | 删除 | 锁定/解锁 | 清除* | 还原 |
| :--------- | :------ | :--- | :-------- | :---- | :--- |
| **正常**   | -       | ✅    | ✅         | -     | ✅    |
| **创建中** | -       | ❌    | ❌         | ❌     | ❌    |
| **删除中** | -       | ❌    | ❌         | ❌     | ❌    |
| **损毁**   | -       | ✅    | ❌         | ❌     | ❌    |



> \* “拍快照”和“清除”操作作用于全局或任务级别，不针对单个快照，详见第四节和第五节。

#### 三、各状态操作详情

**1. 正常**

所有功能正常可用，点击操作按钮直接执行对应功能。

| 操作      | 可用性 | 说明                                           |
| :-------- | :----- | :--------------------------------------------- |
| 还原      | ✅      | 直接执行还原                                   |
| 删除      | ✅      | 点击后弹出确认框“您确定要删除已选择的项目吗？” |
| 锁定/解锁 | ✅      | 点击后切换锁定状态                             |



**2. 创建中**

快照尚未创建完成，数据点不完整，无有效恢复能力，且删除可能导致创建任务异常。

| 操作      | 可用性 | Tooltip                                |
| :-------- | :----- | :------------------------------------- |
| 还原      | ❌ 置灰 | “快照正在创建中，当前不可执行此操作。” |
| 删除      | ❌ 置灰 | “快照正在创建中，当前不可执行此操作。” |
| 锁定/解锁 | ❌ 置灰 | “快照正在创建中，当前不可执行此操作。” |



**3. 删除中**

删除任务已启动，快照资源正在释放。

| 操作      | 可用性 | Tooltip                                |
| :-------- | :----- | :------------------------------------- |
| 还原      | ❌ 置灰 | “快照正在删除中，当前不可执行此操作。” |
| 删除      | ❌ 置灰 | “快照正在删除中，当前不可执行此操作。” |
| 锁定/解锁 | ❌ 置灰 | “快照正在删除中，当前不可执行此操作。” |

**4. 损毁**



快照数据已损坏，无法还原或锁定，但必须允许删除，否则用户会遇到“快照损毁，但无法删除”的困境。

| 操作      | 可用性 | Tooltip / 交互                                   |
| :-------- | :----- | :----------------------------------------------- |
| 还原      | ❌ 置灰 | “快照已损毁，当前不可执行此操作。”               |
| 删除      | ✅ 可用 | 点击后弹出确认框：“您确定要删除已选择的项目吗？” |
| 锁定/解锁 | ❌ 置灰 | “快照已损毁，当前不可执行此操作。”               |

> **说明：** 所有不可用按钮统一使用“状态原因 + 当前不可执行此操作”格式，不再区分具体操作类型（还原/删除/锁定），提高提示语的通用性和一致性。用户通过状态原因（如“快照正在创建中”）即可了解具体限制。



#### 五、“清除”操作 — 独立设计

“清除”为批量删除所有快照的操作，不应继承单个快照删除逻辑。

**方案（推荐）：**

若系统中存在“创建中”或“删除中”状态的快照，清除按钮置灰禁用。

| 场景                          | 按钮状态 | Tooltip                                        |
| :---------------------------- | :------- | :--------------------------------------------- |
| 无处理中快照（全部正常/损毁） | ✅ 可用   | 点击后弹出确认框：“您确定要删除所有的项目吗？” |
| 存在创建中快照                | ❌ 置灰   | “当前存在快照正在创建，不可执行此操作。”       |
| 存在删除中快照                | ❌ 置灰   | “当前存在快照正在删除，不可执行此操作。”       |

> **设计考量** 避免批量删除操作与后台任务冲突，保证数据一致性。

#### 六、UI Tooltip 统一规范

**格式要求：** 状态原因 + 当前限制，不使用“不支持操作”等模糊表述。

|        场景         | Tooltip                                                      |
| :-----------------: | :----------------------------------------------------------- |

|     删除中-还原     | “快照正在删除中，当前不可执行此操作。”                       |
|     删除中-删除     | “快照正在删除中，当前不可执行此操作。”                       |
|     删除中-锁定     | “快照正在删除中，当前不可执行此操作。”                       |
|      损毁-还原      | “快照已损毁，不可执行此操作。”                               |
|      损毁-锁定      | “快照已损毁，不可执行此操作。”                               |
|      损毁-删除      | 按钮正常可用，无 Tooltip（或无需显示）                       |

**是否有异常需要特别处理？**

#### 1.  拍快照操作进行中，页面刷新/关闭

- **场景：** 用户点击“拍快照”后，在任务完成前关闭或刷新浏览器页面。
- **处理：** 后端任务继续执行。用户重新进入快照管理页面时，从后端获取最新状态并刷新 UI。若任务已完成，显示正确的状态。

#### 2. 清除操作与单个删除操作并发冲突

- **场景：** 用户 A 正在执行清除所有快照，同时用户 B 针对单个快照发起删除请求。
- **处理：** 后端加分布式锁，清除操作进行时，所有针对单个快照的删除请求返回错误提示：“当前正在执行清除操作，不可执行此操作。”避免并发冲突导致数据不一致。

#### 3. 锁定状态快照的损毁判定

- **场景：** 已锁定的快照被检测为损毁。
- **处理：** 先解锁再进行删除支持
