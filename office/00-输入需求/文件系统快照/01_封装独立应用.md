## 1. 目前状况

**现状描述：**
文件系统快照功能当前采用分离式页面布局：

- 「设置」页面：负责快照功能的启用/停用、转储间隔、最大快照数量、执行周期等策略配置
- 「快照清单」页面：展示所有快照列表（默认显示Volume1，可通过侧边栏切换其他Volume），支持创建、锁定、删除、回滚等操作

**核心问题：**
① 功能割裂——用户需在两个页面间切换才能完成「先配置策略、后查看快照」的完整操作链路
② 配置入口隐蔽——设置功能独立成页，用户需离开清单页面才能调整策略，增加操作步骤
③ 空状态体验缺失——快照未启用时，清单页面无明确引导，用户不知如何启用
④ 信息密度不合理——设置项较少却独占一个完整页面，浪费空间

------

## 2. 用户价值

- **降低操作路径**：在同一页面即可查看快照清单，点击按钮弹窗调整策略，无需页面跳转
- **减少认知负担**：清单为主、配置为辅，用户始终停留在核心数据视图，配置作为辅助操作
- **清晰的状态引导**：未启用时展示空状态引导页，用户一目了然知道如何开始使用
- **提升效率**：设置弹窗支持即时修改策略，修改后清单列表自动刷新，所见即所得

------

## 3. 用户场景

**场景一：首次启用快照功能**
用户进入文件系统快照模块，看到空状态页面（快照未启用），点击「立即启用」按钮打开设置弹窗，开启快照开关并配置策略后确认，页面切换至快照清单视图。

**场景二：调整快照策略**
用户已在使用快照功能，发现快照数量增长过快，希望调整保留数量。点击工具栏「设置」按钮打开弹窗，修改「最大快照数量」后确认，策略实时生效。

**场景三：查看并管理快照**
用户需要回滚某个时间点的快照。进入快照清单页面，选择目标快照，点击「回滚」操作完成恢复。

**场景四：多Volume切换**
用户有多个存储卷（Volume1、Volume2），通过侧边栏菜单切换，当前Volume的快照列表实时刷新。

## 4. 竞品调研

| 平台       | 页面组织方式          | 设计特点                                         |
| :--------- | :-------------------- | :----------------------------------------------- |
| 群晖 DSM   | 快照与复制 → 快照列表 | 设置入口为独立按钮，弹窗式配置，列表主视图不变   |
| 威联通 QTS | 存储与快照总管        | 左侧卷列表 + 右侧快照表格，设置位于菜单栏        |
| TrueNAS    | Storage → Snapshots   | 列表为主，顶部工具栏包含设置入口，配置弹窗操作   |
| 绿联 UGOS  | 备份与还原 → 快照     | 快照清单为主页，设置入口在右上角，点击跳转子页面 |

**行业共性：**
① 快照清单为核心视图，用户进入默认看到快照数据
② 设置功能多为弹窗或侧拉面板，不离开当前页面
③ 未启用快照时有明确的空状态引导
④ 多卷支持通过侧边栏或下拉切换

## 6. 详细功能要求

### 6.1 页面结构

| 区域     | 组件                | 说明                                     |
| :------- | :------------------ | :--------------------------------------- |
| 侧边栏   | Volume列表          | 展示所有Volume，支持切换，当前激活项高亮 |
| 主内容区 | 快照清单表格        | 显示当前Volume的所有快照                 |
| 工具栏   | 操作按钮 + 设置按钮 | 创建、锁定、删除、清除、设置             |
| 弹窗     | 设置面板            | 包含快照策略配置，操作后立即生效         |

### 6.2 功能定义

| 功能          | 说明                                               |
| :------------ | :------------------------------------------------- |
| 快照清单展示  | 表格展示快照列表（版本、创建时间、锁定状态、操作） |
| 切换Volume    | 点击侧边栏不同Volume，刷新快照列表                 |
| 创建快照      | 手动创建当前Volume的快照                           |
| 锁定/解锁快照 | 锁定后防止被自动删除                               |
| 删除快照      | 删除选中的快照                                     |
| 快照设置      | 弹窗配置启用开关、转储间隔、最大数量、执行周期     |
| 空状态引导    | 未启用快照时展示引导页 + 立即启用按钮              |

### 6.3 设计要点

1. **默认视图**：进入模块默认显示快照清单（若已启用）或空状态（若未启用）
2. **设置弹窗**：
   - 点击工具栏「设置」按钮打开
   - 弹窗包含启用开关和策略配置
   - 确定后配置立即生效，弹窗关闭
   - 若启用开关从关→开，关闭弹窗后页面从空状态切换为清单视图
3. **Volume切换**：通过侧边栏切换，当前Volume高亮，快照列表实时刷新
4. **空状态**：
   - 仅在快照未启用时显示
   - 包含清晰的图标、文案和「立即启用」按钮
   - 按钮点击打开设置弹窗

| :---- | :--------- | :----------------------------------------------------------- |
| AC-01 | 页面入口   | 进入文件系统快照模块，默认显示快照清单（已启用）或空状态（无快照） |
| AC-02 | 设置弹窗   | 点击工具栏「设置」按钮，弹出设置弹窗，背景遮罩可关闭         |
| AC-03 | 启用快照   | 弹窗中开启开关并确认，关闭弹窗后空状态切换为快照清单         |
| AC-04 | 停用快照   | 弹窗中关闭开关并确认，快照清单切换为空状态                   |
| AC-05 | 策略保存   | 修改转储间隔/最大数量/执行周期并确定，配置生效               |
| AC-06 | Volume切换 | 点击侧边栏不同Volume，快照列表刷新为对应Volume的数据         |
| AC-07 | 快照操作   | 创建、锁定/解锁、删除、还原、清除、刷新功能正常              |
| AC-08 | 空状态引导 | 空状态展示「立即启用」按钮，点击打开设置弹窗                 |

## 9. 异常处理

| 异常场景                 | 系统响应                                           | 备注     |
| :----------------------- | :------------------------------------------------- | :------- |
| 快照创建失败（空间不足） | 提示「创建快照失败，存储空间不足」，保留原列表不变 | 日志     |
| 删除被锁定的快照         | 提示「快照已锁定，请先解锁后再删除」               | 气泡提示 |
| 清除包含已锁定的快照     | 无提示，请删除未锁定的快照、锁定的快照仍然保留     | 气泡提示 |
| Volume切换时加载失败     | 提示「加载快照列表失败，请刷新重试」               | 气泡提示 |
