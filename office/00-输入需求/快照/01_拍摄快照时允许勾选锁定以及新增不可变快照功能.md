### 一、拍摄快照弹窗

**触发路径**：快照任务 → 点击「拍快照」按钮 → 弹出弹窗。

弹窗表单字段如下：

| 序号 | 字段名称       | 控件类型            | 说明                                                         |
| ---- | -------------- | ------------------- | ------------------------------------------------------------ |
| 1    | 描述           | 文本输入框          | 选填                                                         |
| 2    | 锁定           | 复选框 + 信息图标 ⓘ | ⓘ 悬浮提示：「锁定后的快照不会被自动清理策略删除」           |
| 3    | 启用不可变快照 | 复选框 + 信息图标 ⓘ | ⓘ 悬浮提示：「启用后，在保护期内任何用户均无法删除此快照」   |
| 4    | 保护期         | 数值输入框          | 仅当勾选「启用不可变快照」时激活；单位支持「天」 ，默认 7 天；最小值 1，最大值 30 天） |

**交互逻辑：**

- 「启用不可变快照」默认未勾选，勾选后激活「保护期间」字段
- 取消勾选「启用不可变快照」时，禁用「保护期间」字段

**二、****快照清单新增列**

快照清单中，新增一列展示快照是否已启用不可变快照以及悬浮展示剩余时间。

### 三、编辑快照弹窗

**触发路径**：快照清单中选中某快照 → 点击「编辑」按钮。

弹窗在「拍摄快照弹窗」基础上增加下方逻辑：

**场景一：快照尚未启用不可变快照**

| 字段           | 状态                                 |
| -------------- | ------------------------------------ |
| 描述           | 可编辑，预填当前值                   |
| 锁定           | 可编辑，预填当前值                   |
| 启用不可变快照 | 未勾选，允许用户勾选并设置保护期间   |
| 保护期         | 禁用态，勾选「启用不可变快照」后激活 |

**场景二：快照已启用不可变快照且处于保护期内**

| 字段           | 状态                                                         |
| -------------- | ------------------------------------------------------------ |
| 描述           | 可编辑，预填当前值                                           |
| 锁定           | 可编辑，预填当前值（锁定与不可变是两个独立维度，不互斥）     |
| 启用不可变快照 | **置灰显示为已勾选，不可取消**                               |
| 保护期         | **只读文本**，显示设定值（如「7 天」）                       |
| 剩余时间       | **只读文本**，新增行，实时显示剩余保护时间（如「6 天 23 小时 58 分钟」） |

**详细的功能验收指标是什么？**

快照在开启不可变快照后，在保护期内不可删除。

已在保护期内的快照，启用不可变的按钮置灰。

### 功能测试

| 测试场景           | 操作步骤                                                  | 预期结果                                     |
| ------------------ | --------------------------------------------------------- | -------------------------------------------- |
| 创建不可变快照     | 拍摄快照 → 勾选「启用不可变快照」→ 设置 1 天保护期 → 确定 | 快照创建成功，快照清单中显示不可变快照图标   |
| 保护期内删除       | 对上述快照点击删除                                        | 置灰删除按钮                                 |
| 保护期结束删除     | 等待保护期过后，尝试删除该快照                            | 删除成功                                     |
| 快照清单编辑页置灰 | 打开处于保护期内的不可变快照编辑页                        | 不可变复选框置灰勾选，保护期间/剩余时间只读  |
| 锁定 + 不可变      | 拍摄快照同时勾选锁定和不可变                              | 两项均生效，互不影响                         |
| 校验最小值         | 保护期输入 0 天或空值                                     | 确定按钮置灰，红色提示「保护期范围为1~30天」 |
