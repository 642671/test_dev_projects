## 二、编写新测试的流程（在编辑器中）

### 场景：要为一个新页面写自动化测试

按以下顺序创建/编辑文件：

#### 步骤 1：创建定位器

文件位置：`ui_automation/pages/locators/xxx_page_locators.py`

```python
from selenium.webdriver.common.by import By

class XxxPageLocators:
    """xxx 页面定位器"""
    USERNAME_INPUT = (By.ID, "username")
    SUBMIT_BUTTON = (By.CSS_SELECTOR, "button[type='submit']")
    ERROR_MESSAGE = (By.CLASS_NAME, "error-msg")
```

#### 步骤 2：创建页面对象

文件位置：`ui_automation/pages/pages/xxx_page.py`

```python
from ui_automation.pages.base_page import BasePage
from ui_automation.pages.locators.xxx_page_locators import XxxPageLocators
from common.logger import get_logger

logger = get_logger("XxxPage")

class XxxPage(BasePage):
    """xxx 页面操作"""
    
    def __init__(self, driver):
        super().__init__(driver)
    
    def do_something(self, text):
        """执行某个操作"""
        self.input_text(XxxPageLocators.USERNAME_INPUT, text)
        self.click(XxxPageLocators.SUBMIT_BUTTON)
        return self
    
    def is_error_visible(self):
        """检查错误是否显示"""
        return self.is_element_visible(XxxPageLocators.ERROR_MESSAGE)
```

#### 步骤 3：创建测试用例

文件位置：根据类型选择目录
- 冒烟测试 → `ui_automation/testcases/smoke/test_xxx.py`
- 功能测试 → `ui_automation/testcases/functional/test_xxx.py`
- 回归测试 → `ui_automation/testcases/regression/test_xxx.py`

```python
import pytest
from ui_automation.pages.pages.xxx_page import XxxPage
from common.logger import get_logger

logger = get_logger("TestXxx")

@pytest.mark.ui
@pytest.mark.functional
class TestXxx:
    """xxx 功能测试"""
    
    def test_something(self, driver, base_url):
        """验证某个功能"""
        page = XxxPage(driver)
        page.open(f"{base_url}/xxx")
        page.do_something("test")
        assert not page.is_error_visible(), "不应显示错误"
        logger.info("测试通过")
```

#### 步骤 4（可选）：添加测试数据

## 三、在终端中运行测试

### 基础命令

```bash
# 运行全部测试（自动生成 HTML 报告）
pytest

# 按标签运行
pytest -m smoke          # 冒烟测试
pytest -m functional     # 功能测试
pytest -m regression     # 回归测试
pytest -m ui             # 所有 UI 测试
pytest -m api            # 所有接口测试

# 运行指定文件
pytest ui_automation/testcases/smoke/test_login_smoke.py

# 运行指定方法（调试时最常用）
pytest ui_automation/testcases/smoke/test_login_smoke.py::TestLoginSmoke::test_valid_login -s
```

### 环境控制

```bash
# 切换到 dev 环境
TEST_ENV=dev pytest -m smoke

# 切换到 prod 环境
TEST_ENV=prod pytest -m smoke
```

### 报告生成

```bash
# HTML 报告（默认自动生成）
# 位置：reports/html/report.html
pytest
open reports/html/report.html    # macOS 直接打开

# Allure 报告（更美观，需要安装 allure 命令行）
pytest --alluredir=reports/allure
allure serve reports/allure      # 启动本地服务查看

# 安装 allure 命令行工具
brew install allure
```

### 高级用法

```bash
# 并行执行（加速）
pytest -m ui -n auto

# 失败自动重跑 2 次
pytest --reruns 2

# 只显示失败信息
pytest --tb=short

# 第一个失败就停止
pytest -x

# 显示最慢的 10 个测试
pytest --durations=10

# 调试模式（失败时进入交互式调试）
pytest --pdb
```

## 五、配置修改指南

### 修改被测网站地址

编辑 `config/environments/test.yaml`：
```yaml
base_url: "https://你的网站地址.com"
```

### 开启/关闭 headless 模式

编辑 `config/environments/test.yaml`：
```yaml
browser:
  type: "chrome"
  headless: true    # true=不显示浏览器，false=显示浏览器
```

### 修改等待超时

编辑 `config/constants.py`：
```python
DEFAULT_TIMEOUT = 10    # 默认等待（秒）
LONG_TIMEOUT = 30       # 长等待
```

或修改 `config/environments/test.yaml`：
```yaml
browser:
  implicit_wait: 10
  page_load_timeout: 30
```
