# 项目目录说明

## 整体结构

```
test_dev_projects/
├── conftest.py              ← 全局 pytest 配置（浏览器初始化、失败截图）
├── pytest.ini               ← pytest 运行规则（标签、报告路径）
├── requirements.txt         ← Python 依赖清单
├── README.md                ← 项目说明
│
├── config/                  ← 【配置中心】环境、常量管理
├── common/                  ← 【公共工具】日志、装饰器、数据加载
├── ui_automation/           ← 【UI 自动化测试】⭐ 主要工作区
├── api_testing/             ← 【接口测试】
├── performance/             ← 【性能测试】
├── testcase_generator/      ← 【测试用例生成器】
├── docs/                    ← 【文档】
├── notes/                   ← 【笔记】
│
├── reports/                 ← 【报告输出】运行后自动生成
│   ├── html/report.html     ← HTML 测试报告
│   └── allure/              ← Allure 报告数据
├── logs/                    ← 【日志输出】自动生成
│   └── pytest.log           ← pytest 运行日志
└── venv/                    ← Python 虚拟环境（不用管）
```

---

## 各模块详细说明

### config/ — 配置中心

| 文件 | 作用 | 什么时候改 |
|------|------|-----------|
| `settings.py` | 读取配置的代码逻辑 | 基本不用改 |
| `constants.py` | 全局常量（超时时间、重试次数、路径等） | 想调整等待时间时 |
| `environments/test.yaml` | 测试环境配置 | 修改被测网站 URL、账号、浏览器设置 |
| `environments/dev.yaml` | 开发环境配置 | 切换环境时 |
| `environments/prod.yaml` | 生产环境配置 | 切换环境时 |

### common/ — 公共工具箱

| 文件 | 作用 |
|------|------|
| `logger.py` | 日志记录，自动按天保存到 logs/ 目录 |
| `decorators.py` | 装饰器：@retry 重试、@screenshot_on_error 异常截图、@log_execution_time 计时 |
| `data_loader.py` | 统一加载测试数据（YAML/JSON），支持 pytest 参数化 |
| `file_handler.py` | 文件读写工具（Excel/YAML） |
| `report_utils.py` | 报告生成辅助工具 |

### ui_automation/ — UI 自动化模块

```
ui_automation/
├── conftest.py                      ← UI 模块 fixtures（driver、base_url）
│
├── pages/                           ← 页面对象层
│   ├── base_page.py                 ← 基类：所有页面操作的基础
│   ├── locators/                    ← 定位器（集中管理元素定位）
│   │   ├── common_locators.py       ← 通用定位器（消息提示、模态框等）
│   │   ├── login_page_locators.py   ← 登录页定位器
│   │   └── dashboard_page_locators.py
│   ├── components/                  ← 可复用组件
│   │   ├── base_component.py        ← 组件基类
│   │   ├── header_component.py      ← 页头（退出登录、用户名）
│   │   └── navigation_component.py  ← 导航菜单
│   ├── pages/                       ← 业务页面对象
│   │   ├── login_page.py            ← 登录页
│   │   └── dashboard_page.py        ← 仪表盘页
│   └── helpers/                     ← 辅助工具
│       ├── wait_helpers.py          ← 自定义等待（AJAX、URL变化等）
│       ├── action_helpers.py        ← 高级操作（拖拽、双击、键盘）
│       └── validation_helpers.py    ← 验证断言（文本、属性、CSS）
│
├── testcases/                       ← 测试用例
│   ├── conftest.py                  ← 用例级 fixtures（预登录用户等）
│   ├── smoke/                       ← 冒烟测试（核心功能快速验证）
│   ├── functional/                  ← 功能测试（完整功能验证）
│   └── regression/                  ← 回归测试（全量回归验证）
│
├── testdata/                        ← 测试数据（YAML 格式）
│   ├── login_data.yaml
│   └── fixtures/                    ← 预置数据集
│       ├── user_fixtures.yaml
│       └── account_fixtures.yaml
│
└── evidence/                        ← 测试证据（自动生成）
    ├── screenshots/                 ← 失败自动截图
    └── page_sources/                ← 页面源码保存
```

### api_testing/ — 接口测试模块

| 目录/文件 | 作用 |
|-----------|------|
| `api_client/base_client.py` | HTTP 请求封装（GET/POST/PUT/DELETE） |
| `testcases/test_example_api.py` | 示例接口测试用例 |
| `testdata/example_api_data.yaml` | 接口测试数据 |

### performance/ — 性能测试模块

| 文件 | 作用 |
|------|------|
| `scripts/example_load_test.js` | k6 负载测试示例脚本 |
| `scripts/README.md` | 性能测试使用指南 |
| `scripts/jmeter_guide.md` | JMeter 使用说明 |

### testcase_generator/ — 测试用例生成器

| 文件 | 作用 |
|------|------|
| `generator.py` | 从测试点生成结构化测试用例 |
| `example_usage.py` | 使用示例 |
| `templates/functional_testcase.yaml` | 用例模板（定义字段格式） |

## 输出目录说明

| 目录 | 内容 | 何时生成 |
|------|------|---------|
| `reports/html/report.html` | HTML 测试报告 | 每次运行 pytest 自动生成 |
| `reports/allure/` | Allure 报告数据 | 加 --alluredir 参数时生成 |
| `logs/pytest.log` | pytest 详细日志 | 每次运行自动生成 |
| `logs/YYYY-MM-DD.log` | 框架日志（按天轮转） | 代码执行时生成 |
| `evidence/screenshots/` | 失败截图 | 测试失败时自动保存 |
| `evidence/page_sources/` | 页面 HTML 源码 | 调用 save_page_source 时 |
