# 跨平台同步指南（macOS ↔ Windows）

## 同步原理

```
┌─────────────────┐         GitHub          ┌─────────────────┐
│   家 (macOS)     │ ←── git push/pull ──→  │  公司 (Windows)   │
│                  │                         │                  │
│  代码 ✓ 同步     │                         │  代码 ✓ 同步      │
│  配置 ✓ 同步     │                         │  配置 ✓ 同步      │
│  数据 ✓ 同步     │                         │  数据 ✓ 同步      │
│  报告 ✓ 同步     │                         │  报告 ✓ 同步      │
│  笔记 ✓ 同步     │                         │  笔记 ✓ 同步      │
│  venv ✗ 不同步   │                         │  venv ✗ 不同步    │
│  （本地重建）     │                         │  （本地重建）      │
└─────────────────┘                         └─────────────────┘
```

**核心原则**：除了 `venv/` 虚拟环境以外，所有内容都同步。`venv/` 在每台机器上各自重建即可。

## Windows 首次设置（在公司电脑上做一次）

### 1. 安装必要软件

#### Python 3.12+
- 下载：https://www.python.org/downloads/
- 安装时 **勾选 "Add Python to PATH"**
- 验证：打开 PowerShell，输入 `python --version`

#### Git
- 下载：https://git-scm.com/download/win
- 安装时选择默认选项即可
- 验证：`git --version`

#### Chrome 浏览器（UI 自动化需要）
- 确保安装了最新版 Chrome

### 2. 克隆仓库

```powershell
# 在 PowerShell 中执行
cd C:\Users\你的用户名\Desktop
git clone https://github.com/你的用户名/test_dev_projects.git
cd test_dev_projects
```

### 3. 创建虚拟环境并安装依赖

```powershell
# 创建虚拟环境
python -m venv venv

# 激活虚拟环境（Windows 用 Scripts\activate）
.\venv\Scripts\activate

# 安装所有依赖
pip install -r requirements.txt
```

### 4. 验证环境

```powershell
python --version       # 应该显示 Python 3.12.x
pytest --version       # 应该显示 pytest 9.x
pytest --collect-only  # 应该能收集到测试用例
```

## 日常工作流

### macOS（家里）

```bash
cd /Users/miaoqi/Desktop/test_dev_projects
source venv/bin/activate

# 开始工作前
git pull origin main

# 工作中...编写代码、运行测试
pytest -m smoke

# 工作结束
git add .
git commit -m "feat: 描述修改内容"
git push origin main
```

### Windows（公司）

```powershell
cd C:\Users\你的用户名\Desktop\test_dev_projects
.\venv\Scripts\activate

# 开始工作前
git pull origin main

# 工作中...编写代码、运行测试
pytest -m smoke

# 工作结束
git add .
git commit -m "feat: 描述修改内容"
git push origin main
```

## macOS vs Windows 命令对照

| 操作 | macOS | Windows (PowerShell) |
|------|-------|---------------------|
| 激活虚拟环境 | `source venv/bin/activate` | `.\venv\Scripts\activate` |
| Python 命令 | `python3`（未激活时） | `python` |
| 打开报告 | `open reports/html/report.html` | `start reports\html\report.html` |
| 设置环境变量 | `TEST_ENV=dev pytest` | `$env:TEST_ENV="dev"; pytest` |
| 查看路径 | `pwd` | `Get-Location` |
| 清屏 | `clear` | `cls` |

## 跨平台注意事项

### 1. 路径问题（已处理）
项目代码中使用了 `os.path.join()` 构建路径，自动适配 `/` 和 `\`，**不需要手动修改任何代码**。

### 2. ChromeDriver
Selenium 4.x 自带 ChromeDriver 管理器，会自动下载匹配的驱动，**两个平台都不需要手动安装 ChromeDriver**。

### 3. 换行符
Git 默认会处理 LF（macOS）和 CRLF（Windows）的转换。如果遇到问题，在 Windows 上执行：
```powershell
git config --global core.autocrlf true
```

### 4. 编码
所有文件使用 UTF-8 编码，YAML 文件的中文在两个平台都能正常读取。

## 常见问题

### Q: Windows 上 `python` 命令找不到？
A: 重新安装 Python，确保勾选 "Add Python to PATH"。或者用 `py` 命令代替。

### Q: Windows 上激活虚拟环境报错 "无法加载文件...因为此系统上禁止运行脚本"？
A: 在管理员 PowerShell 中执行：
```powershell
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
```

### Q: 两边的 Python 版本不一致怎么办？
A: 建议两边都用 Python 3.12+。只要大版本一致（3.12.x），小版本差异不影响使用。

### Q: venv/ 为什么不能同步？
A: 虚拟环境中包含编译好的二进制文件（.so/.dll），这些是平台特定的。macOS 的二进制在 Windows 上无法运行。所以每台机器各自用 `pip install -r requirements.txt` 重建即可，效果完全一样。

### Q: 报告和截图同步会不会太大？
A: 如果截图和报告文件积累太多导致 git push 变慢，可以编辑 `.gitignore` 取消注释最后几行来排除它们。通常刚开始不会有这个问题。
