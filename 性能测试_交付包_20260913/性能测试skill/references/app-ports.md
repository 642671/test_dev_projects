### 1.2 仅绑 127.0.0.1 —— 只能在本机发压 ⚠️

> **含义**：这些端口只监听回环口,**外部压测机根本连不上**。
> 要压就两个办法:① **上机压**(在 NAS 上直接跑压测器);② 先建 **SSH 隧道**把端口映出来(见第二节)。
> 注意:隧道法引入了 SSH 通道这个瓶颈,**只适合小流量功能验证,不能用来测吞吐上限**。

| 应用 | 端口 | 协议 | 绑定范围 | 用途 | 做性能测试时的注意 |
|---|---|---|---|---|---|
| Terai | 18581 | TCP | **仅 127.0.0.1** | AI 搜索 API 服务(`api_service`) | 真正的业务后端;外部压不到,只能上机压 |
| Terai | 18582 | TCP | **仅 127.0.0.1** | AI 搜索专用 Redis | 中间件,不直接压;监控其内存占用与连接数 |
| Terai | 18583 | TCP | **仅 127.0.0.1** | Qdrant 向量库 HTTP | 检索瓶颈点;监控查询延迟,不直接压 |
| Terai | 18584 | TCP | **仅 127.0.0.1** | Qdrant 向量库 gRPC | 同上,gRPC 通道 |
| Openclaw | 18789 / 18799 | TCP | **仅 127.0.0.1** | OpenClaw 网关(nginx 反代 `/terra-openclaw/`) | 网关上还有一层反代,外部请走 18790 侧入口,别压这个 |
| OnlyOffice | 5632 | TCP | **仅 127.0.0.1** | 内置 PostgreSQL | 数据库瓶颈点;监控用,不直接压 |
| TerraSearch | 9200 / 9300 | TCP | **仅 127.0.0.1** | 内置 Elasticsearch(9200=HTTP,9300=节点间) | 仅监控;压它等于绕开应用直接压 ES,不是业务场景 |

## 二、怎么用它

**第 1 步 —— 上机确认真实监听**(源表是纸面清单,实测为准,应用版本不同端口会变):

```bash
ss -lntp                 # TCP 监听(推荐,比 netstat 快)
ss -lnup                 # UDP 监听 —— 8125 statsd 只有这里看得到,别漏
netstat -lntp            # 老系统没有 ss 时用这个
```

判读:`Local Address:Port` 里 `0.0.0.0:8023` = 全网卡可压;`127.0.0.1:18581` = **仅本机**。

**第 2 步 —— 仅本机端口要压,先建 SSH 隧道**(以本工作区常用的 `10.18.15.103` 为例):

```bash
# 把 NAS 上的 127.0.0.1:18581 映到本地 18581(<用户名> 与 <NAS_IP> 按实际替换)
ssh -N -L 18581:127.0.0.1:18581 <用户名>@<NAS_IP>
# 之后本地直接打 http://127.0.0.1:18581 即可
```

> ⚠️ 隧道只适合**功能验证级**的小流量。真要测并发上限,请在 NAS 上直接跑压测器(上机压),隧道带宽与加解密开销会先成为瓶颈,测出来的数不是应用的数。

## 三、常见坑

| 现象 | 原因 | 怎么办 |
|---|---|---|
| 压测报错连不上,但应用明明在跑 | 端口**仅绑 127.0.0.1**,外部压测机路由不到 | 回 1.2 节:上机压或走 SSH 隧道;别怀疑防火墙 |
| 端口被别的应用占用,压出的是别人的数据 | 端口冲突(如 8080/8000 这类常见口) | `ss -lntp` 看 PID/进程名,核对是不是被测应用;报告里写清进程名 |
| 同一应用两次测试端口不一样 | 应用重启后动态分配端口,或版本升级改了默认口 | 每次压测**前**重新 `ss -lntp` 采一次,把端口与 PID 写进报告基线 |
| 监控数据缺一块,压测结论说不清 | **UDP 端口漏采**(statsd 8125 走 UDP) | 采集脚本同时抓 TCP + UDP;`ss -lnup` 单独确认一遍 |
| 压了 18581 结果比 18580 快很多/慢很多 | 18580 是 nginx 反代(多一跳),18581 是后端直连,两者不是同一条链路 | 明确报告压的是哪条链路;对外结论以 18580 为准 |
| 压 Snapshot 时 TOS Web 也卡了 | 5443 与 Web 共用 nginx | 测试环境里避免 Web 操作;或在报告中注明 Web 侧干扰 |
