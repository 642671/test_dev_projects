# TOS 7.1 推荐测试顺序

这份顺序按依赖关系和破坏性排列，不按照片编号排列。每个阶段先完成 P0，再做 P1，最后做 P2；阶段门禁未通过时不要进入下一阶段。

## 0. 环境与证据准备

- 使用隔离测试机、测试 NAS 和可销毁的测试盘；不要把生产盘放进格式化、擦除、RAID 或系统盘迁移场景。
- 记录版本、配置备份、服务启动日志和初始磁盘清单；准备管理员账号和非管理员账号。
- 为每个异步操作保存任务 ID、状态变化、HTTP 响应、服务日志，以及必要的 `lsblk`、`lvs`、`/proc/mdstat`、挂载表结果。
- 所有会改变磁盘、卷、池或系统盘的场景，执行前后都恢复到干净快照或重新初始化测试设备。

## 1. API、配置与服务基线

先确认系统能被稳定观测，再开始破坏性操作。

- `API-001` 至 `API-005`：旧接口结构、类型、嵌套字段和新增接口兼容性。
- `CFG-001` 至 `CFG-006`：配置读取、默认值、旧配置兼容、异常配置处理。
- `CTX-004`、`CTX-005`：优雅退出和资源释放。
- 每项都检查 `/health`、错误码、响应 JSON 和服务日志。

**门禁：** 服务可启动、健康检查稳定、旧接口没有结构性回归。

## 2. 安全与权限

这组不依赖存储数据，优先执行。

- `SEC-001`：非 admin 调用存储 API 返回 403。
- `SEC-002`：外部调用内部接口返回 403。
- `SEC-003`：双斜杠路径拦截或正确路由。
- `SEC-004`：密码只通过 stdin，不能出现在进程参数或 shell 历史。
- `SEC-005`：服务重启不会误杀自身或 `mdadm --monitor`。
- `SEC-006`：错误场景统一 `code_num=60`，错误信息符合约定。
- `ACL-001`：私有 ACL 调用链不经过 Shell 管道。

**门禁：** 权限边界、密码保护和错误码全部通过。

## 3. 异步任务与生命周期

池、卷、RAID、USB 等破坏性操作都依赖这组行为。

- `TASK-001`：并发状态更新不倒退，版本单调递增。
- `TASK-002`：中断后 checkpoint 恢复。
- `TASK-004`：格式化双校验和资源锁互斥。
- `TASK-005`：`CodedError` 结构和稳定错误码。
- `TASK-006`：SIGTERM 下 worker 在限定时间内退出。
- `TASK-008`：数据库恢复后任务管理器自愈。
- `CTX-001`、`CTX-002`、`CTX-003`、`CTX-006`：取消、超时、重启恢复和外部命令上下文。

**门禁：** 每个任务都能观测 `pending -> running -> verifying -> success/failed`，失败时 fail-closed，不遗留锁或半成品。

## 4. 磁盘与设备身份

先验证设备识别，再创建池、RAID 或卷。

- `DISK-007`：SMART 检测。
- `DISK-001`、`DISK-002`、`DISK-003`：格式化、并发互斥和安全擦除。
- `DISK-005`、`DISK-006`：系统 RAID 成员保护和中断恢复。
- `DISK-008`、`DISK-009`：数据擦洗和性能基线。
- `LOCKED-001`：空 NAS 返回 `[]` 而不是 `null`。
- `ID-001` 至 `ID-007`：热备盘 Serial、PTUUID 和弱匹配场景。
- `DI-001` 至 `DI-004`：设备身份漂移和告警。
- `FC-001` 至 `FC-006`：FlashCache 身份匹配。
- `VC-001` 至 `VC-006`、`HW-001`、`WARN-001` 至 `WARN-003`：卷对账、硬件变化和告警展示。

**门禁：** 设备重命名、USB 桥接、重启后对账不误认盘；弱匹配必须产生告警，不能静默绑定错误设备。

## 5. 存储池与 RAID

### 5.1 存储池基础

按下面顺序建立可重复的池生命周期：

1. `POOL-001`、`POOL-002`、`POOL-003`：创建池、创建卷、重启验证挂载。
2. `POOL-004`、`POOL-005`：扩容、删除池。
3. `POOL-006`、`POOL-007`：中断恢复、degraded 池恢复。
4. `POOL-008`、`POOL-009`、`POOL-010`：Btrfs 子卷、池缩容和 RAID reshape。
5. `POOL-011`、`POOL-012`：全局删除保护和删除后底层残留校验。
6. `POOL-013`、`POOL-014`、`POOL-015`、`POOL-016`、`POOL-017`：同名卷组、外来卷组、插盘回收和冲突保护。

### 5.2 RAID 矩阵与修复

- 先按 `RAID-001` 至 `RAID-006` 验证创建、降级、热备、重建和取消。
- 再按 `RAID-007` 至 `RAID-010` 验证多阵列并行、移除 degraded、分区对齐和异常恢复。

**门禁：** 池和 RAID 在重启、拔盘、恢复、删除后都没有遗留 md/VG/LV，且数据保护策略正确。

## 6. 存储卷与格式化

- `VOL-001`、`VOL-002`、`VOL-003`：创建卷、格式化和 `waiting_io` 状态机。
- `VOL-007`：损坏卷显式恢复。
- `VOL-008`：重复挂载/卸载无残留。
- `VOL-009`：ext4/xfs/btrfs 扩容。
- `VOL-010`：Btrfs 子卷漂移校验。
- `VOL-011`、`VOL-012`：双因素 I/O 和同步卷排序。
- `FORMAT-001`、`FORMAT-002`：已挂载卷、Btrfs 子卷挂载时 fail-closed。

**门禁：** 失败不执行危险命令，不创建幽灵任务；成功后挂载、容量和文件系统状态一致。

## 7. 水位与缓存

这些场景要在池和卷稳定后执行。

- `WM-001` 至 `WM-005`：70/85/90/95% 水位、clamp、只读和释放空间策略。
- `CACHE-001` 至 `CACHE-004`：SSD 缓存增删、checkpoint 恢复、三层身份匹配、HyperCache 重启恢复。

## 8. 外接设备与 iSCSI

- `HOTPLUG-001`、`HOTPLUG-002`、`HOTPLUG-003`：USB 插入、移除和连续热插拔。
- `USB-001` 至 `USB-004`：USB/eSATA 格式化、连续切换、ntfs/vfat 权限和列表刷新。
- `ISCSI-001`：实时同步和快照轮询。
- `ISCSI-002`、`ISCSI-003`：映射漂移、stale/refreshing 禁止操作。
- `ISCSI-004`、`ISCSI-005`、`ISCSI-006`：重启对账、空 Target 和 LUN 格式化任务。

## 9. 系统盘、升级与长稳

最后执行高风险、长时间或会改变启动结构的场景。

- `SYS-001`、`SYS-002`、`SYS-003`、`SYS-004`：系统盘迁移、删除、GRUB 回滚和 USB 系统盘保护。
- `UPGRADE-001`、`UPGRADE-002`：7.0 -> 7.1 升级和 7.1 -> 7.0 回退。
- `ROBUST-001` 至 `ROBUST-005`：断电恢复、degraded 修复、慢盘/坏道/I/O Error、iSCSI 断网恢复和 24 小时长稳。

## 10. 最终回归

升级、回退、长稳和重启完成后，重新执行一轮最小回归：

1. `/health`、`API-001`、`API-002`、`API-005`。
2. `SEC-001`、`SEC-002`、`TASK-001`、`TASK-002`。
3. 一个普通卷创建/挂载/卸载场景：`VOL-001`、`VOL-008`。
4. 一个池或 RAID 查询场景，以及一次配置读取：`POOL-001`、`CFG-001`。

每轮结束保存版本、日志、任务状态和底层状态输出，形成可追溯的测试记录。
