# UI自动化文档生成器 - 快速入门

## 什么是UI自动化文档生成器？

这是一个智能工具，可以：
1. **自动执行**UI操作步骤（基于现有的UI自动化框架）
2. **自动截图**每一步的操作结果
3. **自动生成**专业的Word格式测试文档

## 快速开始（3步搞定）

### 第1步：安装依赖

在项目根目录执行：
```bash
python -m pip install python-docx
```

或者双击 `ui_automation/tools/doc_generator/生成文档.bat`，它会自动安装依赖。

### 第2步：准备配置文件

有两种方式：

**方式A：使用示例配置**

已提供示例配置文件：`ui_automation/tools/doc_generator/configs/login_chain.yaml`

这个配置演示了"初始化配置超级用户"的完整登录流程。

**方式B：创建自己的配置**

1. 复制模板文件：
   ```bash
   copy ui_automation\tools\doc_generator\configs\_template.yaml ui_automation\tools\doc_generator\configs\my_test.yaml
   ```

2. 编辑 `my_test.yaml`，填写你的测试链路信息

### 第3步：生成文档

**方式A：使用快捷脚本（推荐）**

双击运行：`ui_automation/tools/doc_generator/生成文档.bat`

然后按提示选择操作即可。

**方式B：使用命令行**

```bash
# 切换到项目根目录
cd d:\test_dev_projects

# 生成示例文档
python -m ui_automation.tools.doc_generator.cli -c ui_automation/tools/doc_generator/configs/login_chain.yaml

# 生成自定义文档
python -m ui_automation.tools.doc_generator.cli -c ui_automation/tools/doc_generator/configs/my_test.yaml

# 批量生成（一次性生成所有配置）
python -m ui_automation.tools.doc_generator.cli --batch ui_automation/tools/doc_generator/configs/*.yaml
```

## 生成的文件在哪里？

### Word文档
位置：`ui_automation/tools/doc_generator/output/`
文件名格式：`{链路名称}_{日期}.docx`

示例：
```
output/
└── 初始化配置超级用户_20260623.docx
```

### 截图文件
位置：`ui_automation/tools/doc_generator/evidence/`
目录格式：`{链路名称}_{日期时间}/`

示例：
```
evidence/
└── 初始化配置超级用户_20260623_143025/
    ├── step_01_打开登录页面.png
    ├── step_02_输入用户名.png
    ├── step_03_点击第一步下一步.png
    └── ...
```

## 配置文件怎么写？

### 最简示例

```yaml
chain_name: "我的测试链路"

environment:
  url: "http://192.168.64.7:8181"

steps:
  - name: "打开页面"
    description: "打开登录页面"
    page: "TosLoginPage"
    action: "open_login_page"
    args: ["${environment.url}"]
    expected: "页面正常加载"
    wait_after: 3
```

### 完整示例

参考 `configs/login_chain.yaml`，包含：
- 链路名称
- 环境信息
- 环境准备说明
- 变量定义
- 多个操作步骤

### 字段说明

**顶级字段：**
- `chain_name`: 链路名称（必填）
- `environment`: 环境信息（必填）
  - `url`: 测试地址
  - `env_name`: 环境名称
- `preparation`: 环境准备说明（可选）
- `variables`: 变量定义（可选）
- `steps`: 操作步骤（必填）

**步骤字段：**
- `name`: 步骤名称（必填）
- `description`: 操作描述（可选）
- `page`: 页面对象类名（必填），如 `TosLoginPage`
- `action`: 方法名（必填），如 `input_username`
- `args`: 参数列表（可选），支持 `${variable}` 占位符
- `expected`: 预期结果（可选）
- `wait_after`: 操作后等待秒数（可选）

## 常见问题

### Q1: 提示找不到模块？
**A:** 确保在项目根目录（`d:\test_dev_projects`）下执行命令。

### Q2: 截图是空的或黑色的？
**A:** 
- 不要使用 `--headless` 模式
- 增加步骤的 `wait_after` 时间，确保页面完全加载

### Q3: 如何知道有哪些页面对象可以用？
**A:** 查看 `ui_automation/pages/pages/` 目录下的文件：
- `tos_login_page.py` → 使用 `TosLoginPage`
- `tos_desktop_page.py` → 使用 `TosDesktopPage`
- `tos_dashboard_page.py` → 使用 `TosDashboardPage`
- 等等...

### Q4: 如何知道页面对象有哪些方法？
**A:** 打开对应的页面对象文件，查看以 `def` 开头的方法定义。

### Q5: 可以批量生成多个链路文档吗？
**A:** 可以！使用 `--batch` 参数：
```bash
python -m ui_automation.tools.doc_generator.cli --batch configs/*.yaml
```
