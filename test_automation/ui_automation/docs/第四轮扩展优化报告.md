## 📝 优化策略总结

### 显式等待的 4 种模式

1. **元素出现等待**: `wait_for_element_visible()`
   - 适用: 页面加载、面板打开、菜单出现
   - 示例: 等待用户名输入框、tooltip、右键菜单

2. **URL 变化等待**: `wait_for_url_contains()`
   - 适用: 页面导航、登录完成
   - 示例: 等待 URL 包含 'desktop'

3. **状态变化等待**: `WebDriverWait(lambda: state_change)`
   - 适用: 按钮状态、复选框勾选、元素可见性
   - 示例: 等待钉住按钮变 active、等待 checkbox.checked

4. **位置变化等待**: `WebDriverWait(lambda: location_change)`
   - 适用: 拖动操作
   - 示例: 等待元素 x/y 坐标变化超过 5px

### 保留 time.sleep 的决策标准

**优化** (替换为显式等待):
- 等待时间 > 1s
- 影响测试稳定性
- 有明确的等待目标 (元素、状态、URL)

**保留** (暂不优化):
- 等待时间 ≤ 0.3s (微等待)
- 动画过渡效果
- 优化复杂度 > 收益
- 无明确等待目标
