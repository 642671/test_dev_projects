# 测试假设与已知限制

本文档记录 UI 自动化和 API 测试中的所有假设、前提条件和已知限制。

---

## 假设清单

### A1: 测试环境可用性
- **假设**: 测试环境 http://192.168.64.7:8181 在测试执行期间始终可用
- **验证方式**: 测试前置 health check
- **如果失败**: 跳过所有测试,报告环境问题
- **影响范围**: 所有 UI 和 API 测试
- **状态**: ✅ 当前有效

### A2: 测试账号有效性
- **假设**: 账号 test/Admin123 始终有效且未被修改
- **风险**: 如果密码被修改,所有登录测试将失败
- **缓解**: 使用环境变量或加密存储敏感凭证
- **影响范围**: 所有需要登录的测试
- **状态**: ✅ 当前有效

### A3: SPA 渲染时间
- **假设**: Vue.js 页面在 3 秒内完成初始渲染
- **证据**: 当前 time.sleep(3) 在测试中有效
- **待优化**: 改为显式等待替代硬编码 sleep (Task 3)
- **影响范围**: 所有 UI 测试
- **状态**: ⚠️ 需优化

### A4: 浏览器兼容性
- **假设**: Chrome 浏览器为主要测试浏览器,Firefox 为可选
- **配置**: ui_automation/config/environments/*.yaml 中的 browser.type
- **影响范围**: UI 自动化测试
- **状态**: ✅ 当前有效

### A5: API 服务可用性
- **假设**: API 基础地址在测试执行期间可访问
- **配置**: api_testing/config/environments/*.yaml 中的 base_url
- **影响范围**: 所有 API 测试
- **状态**: ✅ 当前有效

## 已知限制

### L1: 时间.sleep() 滥用
- **问题**: 多个页面对象中使用 time.sleep() 替代显式等待
- **影响**: 测试执行时间不可控,在慢速网络下可能仍会失败
- **修复计划**: Task 3 - 替换为显式等待
- **状态**: 🔄 计划中

### L2: API 测试覆盖率低
- **问题**: api_testing 模块只有健康检查占位测试
- **影响**: API 功能未得到充分验证
- **修复计划**: 待用户确认 G1 后补充实际 API 测试
- **状态**: 🔄 待确认

### L3: 测试数据组织
- **问题**: 测试数据散落在 testdata/ 根目录,缺乏明确的分类规则
- **影响**: 维护成本高,难以定位测试数据
- **修复计划**: Task 6 - 按功能模块重组目录
- **状态**: 🔄 计划中
