五、API 设计特点
================================================================================

1. 规范性
   - 遵循 OpenAPI 3.0.1 标准
   - 所有接口都有清晰的名称、描述和 operationId
   - 支持 Tag 分类便于组织和理解

2. 版本管理
   - 主要使用 /v2/ 前缀
   - 部分向后兼容的接口使用 /v1/ 前缀
   - 消息中心接口使用简短路径

3. RESTful 设计
   - 使用标准 HTTP 方法 (GET、POST、PUT、DELETE)
   - 资源路径使用明确的命名约定
   - 支持路径参数和查询参数

4. 参数管理
   - 路径参数: /resource/{id}, /resource/{uuid}
   - 请求体: JSON 格式
   - 支持复杂查询和批量操作
