# TOS 桌面模块 功能文档

## 1. 模块概述

TOS 桌面是用户登录 TNAS 后的主入口，是一个运行在浏览器中的 Web 桌面系统。用户通过桌面访问所有 NAS 应用和系统功能。TOS 不是普通网页产品，更像运行在浏览器里的 NAS 桌面操作系统。

## 2. 功能列表

| 子模块 | 功能 |
|--------|------|
| 登录 | 两步式登录（用户名→密码）、保持登录 |
| 开始菜单 | 用户信息、重启/关机/登出、搜索应用、最近访问 |
| 导航栏 | 开始固定+应用图标展示、悬浮提示、单击打开、拖动排序、新增/删除应用、右键菜单 |
| 桌面图标 | 快捷方式展示（桌面任意位置）、默认自动排序、可拖动调整位置、单击打开、右键菜单 |
| 应用窗口 | 打开、关闭、隐藏（双击）、切换、最小化、多窗口共存 |
| 桌面空白右键 | 刷新桌面、进入用户设置 |
| 用户设置-账号 | 用户信息、账号安全、其它 |
| 用户设置-显示 | 显示模式、强调色、壁纸 |
| 桌面右侧栏 | 系统看板、消息通知、搜索、帮助、USB设备（条件）、任务中心（条件） |
| 桌面通知 | 系统操作触发的桌面通知卡片、下拉/展开、删除单个消息、删除所有桌面通知 |
| 会话管理 | 退出登录、会话失效 |

## 3. 功能详细描述

### 3.1 登录

| 项目 | 说明 |
|------|------|
| 入口 | 浏览器访问 TOS 地址 |
| 第一步 | 输入用户名，点击"下一步" |
| 第二步 | 输入密码，可选勾选"保持登录"，点击"下一步" |
| 成功判定 | URL 从 `/#/` 变更为 `/#/desktop`，进入桌面 |

### 3.2 开始菜单

| 项目 | 说明 |
|------|------|
| 入口 | 导航栏最左侧固定图标「开始」，点击弹出面板 |
| 位置 | 开始图标下方弹出 |

**面板布局：**

| 区域 | 内容 |
|------|------|
| 左上角 | 头像、用户名、用户组显示；点击可进入用户设置界面 |
| 右上角 | 重新启动、关机、登出（三个图标） |
| 搜索框 | 提示"请输入应用名称。"；搜索系统已安装应用；结果分"应用搜索结果"和"控制面板搜索结果" |
| 最近访问 | 每行6个应用，最多30个，最新的排最前 |

**搜索功能说明：**
- 开始菜单搜索和桌面右侧栏的搜索功能一致，都调用系统已安装的全局搜索应用

### 3.3 导航栏

| 项目 | 说明 |
|------|------|
| 位置 | 浏览器顶部，横排显示 |
| 默认 | 13个应用图标，「开始」固定最左 |
| 操作 | 单击打开应用、悬浮显示名称、拖动排序、右键弹出菜单（「开始」无右键功能） |
| 规则 | 「开始」不可移动/删除/右键；其他应用可拖动、删除、新增 |
| 持久化 | 自定义排序/增删在刷新/重登后保持 |

### 3.4 桌面图标

| 项目 | 说明 |
|------|------|
| 位置 | 桌面区域（除导航栏和右侧栏外的任意位置） |
| 默认 | 为空 |
| 排序 | 默认自动排序；用户可拖动图标调整位置 |
| 操作 | 单击打开应用、右键弹出菜单 |
| 来源 | 通过导航栏右键"发送到桌面"添加 |

### 3.5 应用窗口

| 项目 | 说明 |
|------|------|
| 打开 | 单击导航栏/桌面图标 |
| 隐藏 | 双击已打开应用的图标 |
| 关闭 | 窗口关闭按钮或右键"关闭" |
| 多窗口 | 支持同时打开多个应用窗口 |

### 3.6 导航栏应用右键菜单

| 应用类型 | 菜单项 |
|----------|--------|
| 常规应用 | 打开/关闭、发送到桌面（置灰规则）、从导航条移除 |
| 部分第三方应用（如Docker、OpenClaw等涉及多用户权限的应用） | 打开/关闭、发送到桌面（置灰规则）、从导航条移除、卸载、权限 |

**置灰规则：** 桌面已有该应用快捷方式时"发送到桌面"置灰

**注：** 并非所有第三方应用都有卸载和权限选项，仅涉及多用户组权限使用的应用才有

### 3.7 桌面图标右键菜单

| 应用类型 | 菜单项 |
|----------|--------|
| 常规应用 | 打开/关闭、固定到导航栏（置灰规则）、删除快捷方式 |
| 部分第三方应用 | 打开/关闭、固定到导航栏（置灰规则）、删除快捷方式、卸载、权限 |

**置灰规则：** 导航栏已有该应用时"固定到导航栏"置灰

### 3.8 桌面空白右键菜单

| 菜单项 | 功能 |
|--------|------|
| 刷新 | 刷新桌面应用状态 |
| 用户设置 | 打开用户设置界面 |
| 创建URL | 暂不关注（后续改版） |

### 3.9 用户设置 - 账号 - 用户信息

| 字段 | 说明 |
|------|------|
| 头像 | 点击更换（本地上传/TNAS文件选择） |
| 描述 | 文本输入 |
| 密码 | 点击编辑图标弹出修改密码弹窗（当前密码+新密码+确认密码） |
| 密保邮箱 | 文本输入 |
| 电话号码 | 文本输入 |
| 存储配额 | 显示"无限制"，不可编辑 |
| 语言 | 下拉框，切换语言提示刷新界面 |

### 3.10 用户设置 - 账号 - 账号安全

| 功能 | 说明 |
|------|------|
| OTP二次验证 | 开关控制，启用后登录需密码+OTP验证码 |

### 3.11 用户设置 - 账号 - 其它

| 选项 | 说明 |
|------|------|
| 不要在登出TOS时提示确认信息 | 勾选框 |
| 不要在重新启动TOS时提示确认信息 | 勾选框 |
| 不要在关机时提示确认信息 | 勾选框 |

### 3.12 用户设置 - 显示

| 功能 | 说明 |
|------|------|
| 显示模式 | 常规/暗黑模式，选中即生效 |
| 强调色 | 5色（蓝/绿/橙/紫/灰），选中即生效 |
| 壁纸 | 预置约22张+上传壁纸（本地上传/TNAS文件选择），选中后选择"设置为桌面壁纸"或"设置为桌面壁纸和登录界面壁纸" |

### 3.13 用户设置 - 交互规则

| 场景 | 行为 |
|------|------|
| 编辑未保存时点击其他模块（如从"账号"切到"显示"）或点击账号下其他标签页（如从"用户信息"切到"账号安全"） | 弹窗"变更尚未保存，您确定要离开吗？"（保存/取消/确认） |
| 切换语言（下拉框选择不同语言） | 提示"为了更新语言设置，所有的页面需要被关闭，您需要重新将它们打开。"（确认→刷新界面且未保存设置不保留/取消→语言不变） |
| 底部"应用"按钮 | 有修改时激活可点击，保存当前设置 |

**未保存弹窗按钮说明：**
- 保存：保存填写的信息并跳转到目标页面
- 取消：不跳转，留在当前编辑页面
- 确认：不保存，直接跳转到目标页面

### 3.14 桌面右侧栏

| 项目 | 说明 |
|------|------|
| 系统看板 | 固定显示 |
| 消息通知 | 固定显示 |
| 搜索 | 固定显示（功能来源为全局搜索应用） |
| 帮助 | 固定显示 |
| USB设备 | 仅当存在未用于创建存储池的USB设备时出现 |
| 任务中心 | 仅在文件管理上传文件时出现 |

### 3.15 桌面通知

| 项目 | 说明 |
|------|------|
| 触发 | 系统部分操作（如登录检测、安全扫描等）触发 |
| 显示 | 通知卡片在桌面右侧显示 |
| 展开/下拉 | 消息卡片支持下拉展开查看详情 |
| 删除单个 | 可删除单个消息通知 |
| 删除所有 | 可一键删除当前所有桌面通知 |
| 保留 | 保留在右侧栏消息通知中 |

### 3.16 会话管理

| 项目 | 说明 |
|------|------|
| 退出登录 | 旧会话失效，返回登录页 |
| 刷新页面 | 桌面恢复正常状态 |
