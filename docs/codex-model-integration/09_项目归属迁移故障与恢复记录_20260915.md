## 恢复方案

1. 等 Codex、后台任务进程和代码模式进程全部退出。
2. 备份 `.codex-global-state.json`、`state_5.sqlite`、`sqlite\codex-dev.db` 以及存在的 WAL/SHM 文件，并生成 SHA-256 清单。
3. 将 133 条历史桌面任务归属映射到当前桌面项目 ID。
4. 从 `projectless-thread-ids` 移除这 133 条明确记录，不改动其他无项目任务。
5. 将 `state_5.sqlite` 中存在的 131 条任务映射到当前 App Server 项目 ID。
6. 将 `codex-dev.db` 中的 133 条目录记录映射到当前 App Server 项目 ID，并递增目录 revision。
7. 设置 `threadAssignmentsMigrated=true`，避免下次启动重复执行失败的迁移。
8. 重新启动 Codex，检查项目及任务数量；如验证失败，从本次时间戳备份恢复。

执行脚本：`scripts\repair-test-dev-project-assignments.ps1`

备份目录：`backups\project-assignment-YYYYMMDD-HHMMSS\`

最终执行结果保存在对应备份目录的 `repair-result.json`，备份文件校验值保存在 `backup-manifest.json`。
