# 操作与验证

## 日常启动顺序

1. CCSwitchMulti（已配置开机自启、静默启动，保持运行）。
2. Clash Verge（规则模式，禁止全局模式）。
3. Codex Desktop。

## 切换模型

- 在 Codex 底部模型选择器中选择模型；一个已打开的会话会继续使用它启动时选择的模型，切换后后续请求才走新模型。
- 常用模型：`9007deepseek-v4-flash`（公司 9007）、`GPT-5.6-Terra`（官方兜底）、`GLM-5.2 (SiliconFlow)`、`GLM-5.3 (Zhipu)`。
- 离开公司网络时，不要使用 `9007deepseek-v4-flash`，请切回 GPT 等外部可用模型。

## 连通性验证

### 公司 9007 网关

```powershell
curl.exe -s -o NUL -w "%{http_code}" http://10.18.10.140:9007/v1/models -H "Authorization: Bearer <公司认证 Key>"
```

返回 `200` 说明网关可达且认证有效；Key 不在文档中保存。

### 本地代理

```powershell
$auth = Get-Content "$env:USERPROFILE\.codex\auth.json" -Raw | ConvertFrom-Json
curl.exe -s -o NUL -w "%{http_code}" http://127.0.0.1:15721/v1/models `
  -H "Authorization: Bearer $($auth.tokens.access_token)" `
  -H "x-cc-switch-proxy-mode: router" `
  -H "ChatGPT-Account-Id: $($auth.tokens.account_id)"
```

裸请求不带认证头会返回 `403`；带齐上面三个头后实测返回 `200`。

### 路由冒烟脚本

```powershell
powershell -ExecutionPolicy Bypass -File D:\test_dev_projects\ccsm_route_test.ps1
```

脚本会读 `~/.codex/auth.json` 构造请求头，向本地代理发一次 `gpt-5.6-terra` 请求；输出末尾的 `HTTP_CODE` 应为 `200`。

发送一次请求后查看：

- `C:\Users\twm\.cc-switch\logs\codex-router.log`：应有 `model=...`、`upstream_url=http://10.18.10.140:9007/v1/responses`、`status=200`。
- `C:\Users\twm\.cc-switch\logs\cc-switch.log`：应有 `[Codex] >>> 请求目标: http://10.18.10.140:9007/v1/responses (model=deepseek-v4-flash)`。

## 网络分流要点

1. Clash Verge 必须使用规则模式；全局模式会把公司内网地址也送进代理导致失败。
2. `Merge.yaml` 的 `rules` 中，内网直连规则必须放在 `MATCH` 之前：
   - `IP-CIDR,10.18.10.140/32,DIRECT,no-resolve`
   - `IP-CIDR,10.0.0.0/8,DIRECT,no-resolve` 等内网段
   - `DOMAIN-SUFFIX,chatgpt.com,<代理组>`、`DOMAIN-SUFFIX,openai.com,<代理组>`
3. 完整 YAML 示例见 `05_9007公司模型接入手册.md`。

## config.toml 生效配置要点

```toml
model_provider = "codex_model_router_v2"
model = "deepseek-v4-flash"

[model_providers.codex_model_router_v2]
name = "Codex GPT + DeepSeek"
base_url = "http://127.0.0.1:15721/v1"
wire_api = "responses"
http_headers = { x-cc-switch-proxy-mode = "router" }
```

注意：`config.toml` 第 6 行的 `model = "deepseek-v4-flash"` 是遗留默认值，模型目录里没有这个 ID（真实 ID 是 `deepseek-v4-flash-noontec-9007` 或 `deepseek-v4-flash-deepseek`）。当前生效依赖会话内模型选择；若要让新会话默认走 9007，应改为 `model = "deepseek-v4-flash-noontec-9007"`。

修改 provider、默认模型或 `base_url` 后需要重启 Codex 才生效。
