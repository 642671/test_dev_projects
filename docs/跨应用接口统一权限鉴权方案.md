# 跨应用接口统一权限鉴权方案

> 适用：TOS 系统所有应用（存储管理、iSCSIManager、用户管理等）

---

## 一、背景与问题

### 1.1 现状

- 权限模型为"用户 — 接口归属应用"绑定：接口归属哪个应用，就按用户对该应用的权限放行；
- 存储管理应用对普通用户一刀切：普通用户不可访问存储管理应用、不可调用其接口。

### 1.2 问题场景

```
普通用户张三（被授予 iSCSIManager 应用使用权限）
        │ 使用 iSCSIManager 前端
        ▼
iSCSIManager 前端 ──调用──► GET /v2/storage/list/volume
                                   │ 该接口归属存储管理应用
                                   ▼
                        存储管理按"接口归属应用"校验：
                        普通用户？拒绝 ✗
```

iSCSIManager 前端会借调存储管理的接口（如 `GET /v2/storage/list/volume`）。张三使用被授权的 iSCSIManager 时，借调请求被存储管理按普通用户拒绝，导致应用无法正常使用。

### 1.3 根因

1. 权限校验只认"接口归属应用"，没有"调用方应用身份"维度；
2. 接口可被多个应用调用，但授权模型不支持"跨应用借调"；
3. 原设计未考虑"普通用户被授权某应用后，该应用需要调用其他应用的接口"。

---

## 二、方案目标

1. **普通用户被授予某应用权限后，该应用使用过程中调用的所有接口（含借调的其他应用接口）均可正常调用**；
2. 授权边界不扩大：普通用户直接访问未授权应用的接口，仍被拒绝；
3. 应用入口统一由 `GET /v2/desktop/list` 提供，仅返回当前用户有权限的应用；
4. 不引入接口白名单机制，采用统一身份鉴权，规则单一、无维护成本。

---

## 三、核心概念

| 概念 | 说明 |
| --- | --- |
| 应用 | 权限授予的最小单元，如存储管理、iSCSIManager、用户管理等 |
| 调用方应用 | 发起接口调用的应用（前端所在应用） |
| 接口归属应用 | 接口所属的应用（仅用于展示/入口，不参与权限判定） |
| 用户-应用授权表 | 服务端维护的授权关系：用户、应用、x 值；权限变更实时生效，无需重新登录 |
| x | 应用级鉴权值，由服务端在 token 鉴权时根据授权表计算，前端不可见、不可修改 |

---

## 四、权限模型（x 值语义）

| x 值 | 身份/状态 | 访问应用 | 调用该应用（作为调用方）接口 |
| --- | --- | --- | --- |
| 1 | 超级管理员 | 全部应用可访问 | 全部可调用 |
| 2 | 管理员 | 全部应用可访问 | 全部可调用（与 x=1 权限无差别） |
| 3 | 普通用户 · 未授权 | 不可访问 | 不可调用（403） |
| 4 | 普通用户 · 被授权 | 该应用可访问 | 该应用全部接口可调用（对该应用拥有超管权限） |

### 4.1 关键规则

1. 权限校验**只看"当前用户对调用方应用的 x 值"**，与接口归属应用无关；
2. x=1、x=2、x=4 均放行；x=3（或应用不在授权表中）拒绝并返回 403；
3. x=1 与 x=2 仅身份标识不同，接口权限完全一致；
4. 普通用户被授予应用后，该应用内 x=4（对该应用拥有超管权限），因此该应用借调其他应用接口时同样按 x=4 放行；
5. x 由服务端在 token 鉴权时计算，前端不可见、不可修改；
6. 应用入口（/v2/desktop/list）与接口权限校验使用同一张授权表，保证"能看到的应用必能调通、看不到的应用必被拒绝"。

---

## 五、鉴权流程

### 5.1 应用入口获取

登录后前端调用现有接口 `GET /v2/desktop/list?AllApplication=undefined`：

- 服务端按"用户-应用授权表"过滤，**只返回当前用户有权限的应用**，无权限应用不出现；
- 超管/管理员：返回全部应用；普通用户：仅返回被授予的应用。

### 5.2 调用阶段

```
前端调用 ──► 网关/统一中间件
                 ├─ 1. 从会话取出用户身份
                 ├─ 2. 从请求取出"调用方应用标识"（前端声明）
                 ├─ 3. 服务端查该用户对该应用的授权，注入 x
                 ├─ 4. 校验 x：3/未授权 → 403；1/2/4 → 放行
                 ▼
              业务接口（业务代码无感）
```

### 5.3 场景验证（iSCSIManager 借调）

```
普通用户（被授予 iSCSIManager）登录后
  │ 调用 /v2/desktop/list?AllApplication=undefined
  ▼
返回：仅包含 iSCSIManager（存储管理等未授权应用不出现）

普通用户使用 iSCSIManager 前端
  │ iSCSIManager 前端调用
  ▼
GET /v2/storage/list/volume + 调用方应用标识 = iSCSIManager
  ▼ 校验：服务端查授权表，用户对 iSCSIManager 的 x=4 → 放行 ✓
─────────────────────────────────────────────
普通用户直接调存储管理接口 + 调用方应用标识 = storage_manager
  ▼ 校验：授权表中用户对 storage_manager 无授权 → 403 ✓
```

## 六、接口覆盖范围

| 接口类型 | 是否走 x 鉴权 | 说明 |
| --- | --- | --- |
| 所有应用的业务接口 | 是 | 统一拦截器覆盖，接口代码无感 |
| /v2/desktop/list（入口） | 服务端按授权表过滤 | 仅返回当前用户有权限的应用 |
| 登录/鉴权链路接口 | 否（发起点） | 登录、刷新 token、登出、验证码获取 |
| 公开基础接口 | 否（显式登记例外） | RSA 公钥、图片验证码、健康检查等 |
| 服务间调用接口 | 走服务凭证（不走用户 x） | 应用后端直连其他应用后端时 |

**兜底规则：未登记为"公开例外"的接口，默认全部走 x 校验（默认拒绝）。**

---

## 七、实现要点

1. **用户-应用授权表**：服务端维护（用户、应用、x 值），作为入口展示与接口校验的唯一数据源；权限变更实时生效，无需重新登录；
2. **/v2/desktop/list 过滤**：服务端按授权表过滤返回，仅输出当前用户有权限的应用；
3. **统一拦截器**：后端框架级中间件（或网关层）统一完成"token 鉴权 → 查授权表 → 计算 x → 校验"，业务接口零改动自动生效；
4. **调用方应用标识**：前端请求需携带调用方应用标识（header 如 `X-App-Id` 或按 URL 前缀推断）；
5. **x 服务端计算，禁止前端自报**：前端只声明调用方应用标识，x 由服务端根据授权表计算，防止伪造提权；
6. **服务间调用**：应用后端直连其他应用后端时使用服务级凭证鉴权，与用户 x 通道分离；
7. **接口归属应用仅用于展示**：菜单、入口、文档展示仍按归属应用组织，但不参与权限判定。

---

## 八、落地步骤

1. **梳理用户-应用授权表**：明确数据来源（权限管理界面/接口）与维护方式；
2. **/v2/desktop/list 按授权表过滤**：仅返回当前用户有权限的应用；
3. **定义例外清单**：登录、验证码、RSA 公钥、健康检查等公开接口登记为例外；
4. **实现统一拦截器**：token 鉴权 → 查授权表 → 计算 x → 校验，默认拒绝，未授权一律 403；
5. **前端全面排查**：所有应用的前端调用补齐"调用方应用标识"（存量改造的大头，按应用逐个过）；
6. **灰度验证**：先在存储管理、iSCSIManager 启用，跑权限验证矩阵，再全量推广。

---

## 九、风险与边界

| 风险 | 说明 | 应对 |
| --- | --- | --- |
| 授权粒度是应用级 | 授权一个应用 = 该应用身份可调全部接口 | 本方案预期行为；如后续需要接口级限制，再引入接口级控制（届时重新设计） |
| 伪造调用方身份 | 前端伪造应用标识提权 | 调用方应用标识由服务端校验，x 由服务端计算，前端不可信 |
| 入口与校验不一致 | 能看到但调不通 / 看不到但能调通 | /v2/desktop/list 与接口校验必须同源（同一张授权表） |
| 存量前端遗漏 | 老接口未带应用标识被默认拒绝 | 前端逐应用排查清单 + 灰度期日志监控 403 来源 |
| 服务间调用误走用户通道 | 后端直连被用户 x 误杀 | 服务凭证通道与用户 x 通道分离 |

| 场景 | 用户 | 调用方应用 | 预期 |
| --- | --- | --- | --- |
| 应用入口 | 超管 | /v2/desktop/list | 返回全部应用 |
| 应用入口 | 管理员 | /v2/desktop/list | 返回全部应用 |
| 应用入口 | 普通用户 | /v2/desktop/list | 仅返回被授权应用 |
| 直接调用 | 超管 | storage_manager | 200 |
| 直接调用 | 管理员 | storage_manager | 200 |
| 直接调用 | 普通用户（未授权） | storage_manager | 403 |
| 借调 | 普通用户（已授权 iSCSIManager） | iSCSIManager → storage_manager 接口 | 200 |
| 借调 | 普通用户（未授权 iSCSIManager） | iSCSIManager → storage_manager 接口 | 403 |
| 伪造提权 | 普通用户 | 伪造调用方应用/伪造 x | 403 |
