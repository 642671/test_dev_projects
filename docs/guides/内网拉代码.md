# 内网拉取代码操作说明

各位好，内网拉取项目代码可以参考以下流程：

## 一、登录内网 GitLab

1. 在内网环境访问：http://gitlab.local
2. 使用公司邮箱登录，邮箱后缀为 `@noontec.net`。
3. 输入个人自定义密码；默认密码为 `Admin123`。

## 二、获取项目权限

1. 先与对应开发确认项目代码仓库名称。
2. 如无访问权限，请联系开发主管蒋强开通代码权限。
3. 获取权限后，进入对应项目仓库。

## 三、拉取或下载代码

1. 进入项目后，界面操作方式与 GitHub 类似。
2. 建议为常用项目添加星标，后续可在【项目】模块的【已加星标】中快速找到仓库。
3. 进入项目页面后，点击【代码】，即可将代码下载到本地使用，要用liunx环境的就下载到linux环境。

## 四、内外网文件传递

部分项目需要在 Linux 环境中执行，可能依赖 Go 环境等。如需从外网向内网传递安装包、插件或其他文件，可参考以下方式：

1. 外网传入内网地址：
   `\\10.18.15.11\share_public`
2. 账号/密码：
   `share / 123456`
3. 建议创建个人文件夹，避免与他人文件冲突。
4. 在内网访问：
   `\\10.18.10.137\share_internal`
5. 找到自己的文件夹后，即可查看已传入的文件。

## 五、VS Code 代理与插件

1. VS Code 代理配置建议由开发主管蒋强提供准确可用的指令集合。
2. 配置代理后，可以直接在 VS Code 中下载插件。
3. 也可以在外网 VS Code 插件商店下载对应插件的 VSIX 文件，传入内网后，在 VS Code 中选择“从 VSIX 安装”。

## 六、Claude / CC Switch 配置

Claude 的配置方式与外网一致，大家可以使用自己的配置方式；也可以自行从外网传入 CC Switch 应用进行统一管理。
