## pytest 测试运行

### 按标签运行

| 命令 | 说明 |
|------|------|
| `pytest` | 运行全部测试 |
| `pytest -m smoke` | 冒烟测试 |
| `pytest -m functional` | 功能测试 |
| `pytest -m regression` | 回归测试 |
| `pytest -m ui` | 所有 UI 测试 |
| `pytest -m api` | 所有接口测试 |
| `pytest -m "smoke and ui"` | UI 冒烟测试 |
| `pytest -m "not slow"` | 排除慢测试 |

### 按路径运行

```bash
# 运行指定目录
pytest ui_automation/testcases/smoke/

# 运行指定文件
pytest ui_automation/testcases/smoke/test_login_smoke.py

# 运行指定类
pytest ui_automation/testcases/smoke/test_login_smoke.py::TestLoginSmoke

# 运行指定方法
pytest ui_automation/testcases/smoke/test_login_smoke.py::TestLoginSmoke::test_valid_login
```

### 输出控制

| 命令 | 说明 |
|------|------|
| `pytest -v` | 详细输出（默认已开启） |
| `pytest -s` | 显示 print 和日志输出 |
| `pytest -x` | 第一个失败就停止 |
| `pytest --maxfail=3` | 失败 3 个后停止 |
| `pytest --tb=short` | 简短错误信息 |
| `pytest --tb=no` | 不显示错误堆栈 |
| `pytest -q` | 安静模式 |

### 高级功能

| 命令 | 说明 |
|------|------|
| `pytest -n auto` | 并行执行 |
| `pytest --reruns 2` | 失败重跑 2 次 |
| `pytest --durations=10` | 显示最慢的 10 个测试 |
| `pytest --pdb` | 失败时进入调试 |
| `pytest --lf` | 只运行上次失败的 |
| `pytest --co` | 只列出测试，不执行 |

### 环境切换

```bash
TEST_ENV=dev pytest -m smoke      # dev 环境
TEST_ENV=test pytest -m smoke     # test 环境
TEST_ENV=prod pytest -m smoke     # prod 环境
```
