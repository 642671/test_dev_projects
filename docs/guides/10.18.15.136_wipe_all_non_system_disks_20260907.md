# 10.18.15.136 非系统盘清空记录

- 日期：2026-09-07
- NAS：`10.18.15.136`，hostname `TNAS`
- 保护盘：`/dev/sdza`，未做任何修改
- 结果：其余 14 块物理盘已重建为单个未格式化 GPT 分区

## 1. 已处理磁盘

`/dev/sda`、`/dev/sdb`、`/dev/sdc`、`/dev/sdd`、`/dev/sde`、`/dev/sdf`、`/dev/sdg`、`/dev/sdh`、`/dev/sdi`、`/dev/sdj`、`/dev/sdk`、`/dev/sdl`、`/dev/sdm`、`/dev/sdzb`。

每块盘的处理方式：

```text
wipefs -a /dev/sdX
parted -s /dev/sdX mklabel gpt
parted -s /dev/sdX mkpart primary 1MiB 100%
wipefs -a /dev/sdX1
```

最终每块盘只有一个 `sdX1` GPT primary 分区，没有文件系统、没有 RAID/LVM 签名。

## 2. 系统盘保护

`/dev/sdza` 保持原状：

```text
sdza2 -> md9 -> / (ext4)
sdza3 -> md8 -> swap
md8/md9 active
```

没有执行任何针对 `/dev/sdza` 的 wipe、parted 或 mdadm 操作。

## 3. 执行过程中的处理

第一轮直接格式化时，`StorageManager` 的 `vgs/lvs` 进程持有所有原始磁盘，导致 `parted` 只能写入分区表但不能通知内核。第二轮临时停止并屏蔽 `StorageManager.service` 后完成：

```text
RESULT=completed
StorageManager.service -> active (running)
```

服务结束后已恢复正常，TOS 接口仍可返回：

```text
GetDiskListData -> 200
GetDiskStatus   -> 200
disk count      -> 15（含 sdza）
```
