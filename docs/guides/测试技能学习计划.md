## 四、各技能详细学习内容

### 1. Linux 指令（贯穿全程，每天 15~20 分钟）

学习顺序（从常用到进阶）：
1. 文件与系统：ls、cd、pwd、cat、tail -f、find、grep、df -h、du、ps、top、free、mount、uname
2. 网络：ss/netstat、curl、ping、nc
3. 权限与用户：chmod、chown、sudo、whoami、useradd
4. 存储（NAS 重点）：lsblk、blkid、fdisk -l、smartctl、btrfs subvolume list、mount
5. 管道与脚本：|、>、>>、xargs、awk、sed、cron、systemctl、journalctl

练习场：
- NAS 真实环境（首选）：`ssh test@<IP> -p 9222`，只读命令练习：df -h、lsblk、cat /usr/lib/version（TOS 版本）、btrfs subvolume list /Volume1
- 本地 WSL2：安装 Ubuntu 后练习文件操作与脚本，不影响真实 NAS

交付物：一份自己的《NAS 只读命令速查》笔记；能用一条管道命令（如 ps aux | grep xxx）完成排查。

### 2. Postman（第 1~2 周）

- 请求构造：GET/POST、Headers、Body（JSON/form）、鉴权（token 提取）
- 集合与文件夹管理；环境变量/全局变量（{{var}}）
- 断言（Tests）：状态码、响应字段、响应时间
- 数据驱动：CSV/JSON 参数化 + Runner 批量执行
- CLI：newman 跑集合、集成到命令行

练习任务：把 NAS 登录→拿 token→调快照接口→断言 做成一个完整集合，覆盖正常/异常场景。

### 3. Apifox（第 1~2 周）

- 接口设计与文档：从需求/抓包建接口、Schema、字段校验
- Mock：按接口定义生成模拟数据
- 调试与用例：单接口用例、断言、提取变量
- 测试场景：多接口串联（登录→操作→清理）
- 文档导出：OpenAPI/HTML/Markdown；Apifox CLI 自动化运行

练习任务：与 Postman 同步同一套 NAS 接口；用 Apifox CLI 跑一遍已有项目（如 tos7 项目 8019149）的用例。

### 4. Fiddler（第 2~3 周）

- 代理原理与 HTTPS 解密（安装根证书）
- Filters 过滤（只留目标域名/接口）
- 断点（Breakpoints）：修改请求/响应后再放行
- AutoResponder：把真实响应替换为本地 mock（复现“未知状态”）
- 脚本：OnBeforeRequest / OnBeforeResponse 简单改写
- 手机抓包（设置代理）

练习任务：抓 NAS 登录→快照接口全流程；用 AutoResponder 只改 status 字段，观察前端行为（复刻之前 FSS-D05 的状态未知实验）。

### 5. Python（第 3~6 周）

- 基础（第 3~4 周）：语法、数据结构、函数、类、文件读写、异常、虚拟环境（venv）
- 测试方向（第 5 周）：pytest（fixture、断言、参数化）、requests（接口调用、token 管理）
- 工程方向（第 6 周）：openpyxl（Excel 报表）、paramiko/fabric（SSH）、日志与配置文件

练习任务：把 Postman 集合里的 NAS 流程改写为 pytest 冒烟脚本；把测试结果写入 Excel（参照现有 build_excel.py 用法：py -3 + PYTHONIOENCODING=utf-8）。

### 6. JMeter（第 7~9 周）

- 基础（第 7 周）：Test Plan、Thread Group、HTTP Sampler、Listener、查看结果
- 进阶（第 8 周）：参数化（CSV）、关联（正则/JSON 提取）、断言、思考时间、梯度加压
- 分析（第 9 周）：TPS、响应时间分布、P50/P95/P99、错误率，产出报告

练习任务：对快照批量创建接口做一次压测，给出 TPS 与响应时间分布报告（对应之前存储性能 P50/P95 的测量场景）。

### 7. Go（第 10~16 周）

- 基础（第 10~12 周）：语法、变量/函数/结构体、错误处理、go mod 包管理
- 进阶（第 13~14 周）：goroutine 与 channel、HTTP 客户端/服务、JSON 处理
- 工具方向（第 15~16 周）：go test、命令行工具（flag）、并发压测（vegeta / ghz / 自写）

练习任务：写一个并发调用 NAS 快照接口的小工具；用 go test 覆盖核心逻辑；对比 Python 与 Go 在并发场景的表现。
