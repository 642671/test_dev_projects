## 常用操作速查

```bash
# 跑全部测试（pytest.ini 已指向 test_automation/）
py -m pytest

# 只跑接口测试
py -m pytest test_automation/api_testing/testcases

# 体检用例表（八Sheet九维检查）
node tools/api_case_pipeline/all_sheet_check.js

# Excel↔Apifox 对账
node tools/api_case_pipeline/reverse_check.js
```

> ⚠️ `python`/`pip` 不在 PATH，一律用 `py -m` 前缀；依赖缺失时 `py -m pip install <包名>`。
