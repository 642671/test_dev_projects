## 三、主要测试点摘要

### 1. 单词拼写与 UI 文案

- 界面英文文案无拼写错误、英文界面无中文残留
- 中英文切换后文案一一对应
- 代码、脚本、接口路径拼写正确
- 导出文件命名包含模块名、版本号、时间戳

### 2. 语言变量与国际化

- 语言文件覆盖系统支持语种，key 数量一致、无空值
- 变量与占位符数量匹配，无字符串拼接
- 前后端无硬编码用户可见文本
- 术语翻译一致，标点规范

### 3. 日志管理

- 日志统一存放于规范位置（`/var/syslog` 等）
- 关键操作生成完整日志（时间戳、操作类型、对象、结果）
- 配置 logrotate、大小限制、过期清理
- 日志分级正确，生产环境关闭 DEBUG
- 快照任务记录不可变更，事件类型与 PRD 一致

### 4. 文件与存储管理

- 安装目录、临时文件、缓存管理规范
- 空间不足时优雅提示，不崩溃
- 卸载后无目录、进程、配置残留
- 快照数据位于规范路径并与 Volume 对应
- 快照保留策略与执行周期联动正确：未达最大数量时到点自动生成快照；已达最大数量时按保留策略处理，数量不超过上限
- 最大快照数量仅约束新快照创建，解锁快照不受上限限制（未锁定数量可超过最大值）

### 5. 输入校验与异常处理

- 表单格式、边界值（空/0/负数/超长/最大值）校验
- 同名资源与重复提交有提示/防重复
- 依赖服务异常、接口阻塞、超时处理正确
- 错误信息包含原因与方案，不泄露敏感信息
- 接口必填与枚举参数契约校验

### 6. 安全与权限

- 权限基于系统用户/用户组，普通用户不能执行管理操作
- 未登录、Token 失效、CSRF、无权限访问被正确拦截
- 配置与日志无明文密码、密钥、Token
- 强制 HTTPS；危险操作（删除、格式化、还原）有二次确认

### 7. 代码质量

- 命名与注释规范，无过时注释
- 无硬编码 IP、端口、路径、密钥
- 异常捕获完整，错误码契约统一

### 8. 功能逻辑

- 存储管理：磁盘→存储池→卷→格式化/挂载全链路、任务状态、UI/API/后台三层一致性、并发冲突、磁盘插拔回归
- 文件系统快照：对象状态与任务结果分离（缺陷回归）、状态机流转、还原元数据、损坏快照二次校验、30 分钟超时、任务中心记录/筛选/导出、独立应用主流程、三层一致性、重复与并发操作
- 损坏快照仅可删除；已锁定损坏快照不能直接删除，需先解锁再删除

### 9. UI 与用户体验

- 布局无错位重叠，空数据状态友好
- 加载、成功、失败反馈明确，防连点
- 快照空状态引导、状态图标颜色、进度展示
- 设置弹窗不触发整页刷新，取消不保存

### 10. 性能与资源占用

- 页面加载 <3 秒，批量操作响应合理
- 内存、CPU、磁盘 I/O 占用正常
- 10000 个快照列表加载 <2 秒（含状态查询）
- 任务中心保留最近 10000 条记录，查询筛选 <1 秒

### 11. 兼容性

- Chrome/Edge/Firefox/Safari 功能一致
- 不同操作系统、新旧版本与 API 向前兼容
- btrfs 卷支持快照，ext4 卷提示明确不可用

## 四、已识别关键风险

| 级别 | 风险点 | 后续处理 |
| --- | --- | --- |
| P0 | 快照“对象状态”被“任务结果”污染（还原失败/成功后点击快照记录被改写） | 补充状态分离回归用例并验证 |
| P0 | 只读接口 Token 失效、无权限仍返回正常数据 | 先复核测试环境变量，再补充鉴权用例并验证 |
| P1 | 只读接口参数校验缺失（必填/枚举不生效） | 补充参数契约用例并推动修复 |
| P1 | 磁盘插拔后接口阻塞、Loading 卡死 | 回归磁盘插拔用例（已生成 18 条） |
| P2/P3 | 快照状态查询超时、强制删除、已过期状态、接口路径契约等未确认项 | 与产品/研发确认后补充用例 |
