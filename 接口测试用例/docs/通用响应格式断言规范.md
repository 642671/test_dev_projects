# 接口断言规范文档（台账）

> 适用范围：TOS 单接口测试（Apifox），所有返回通用响应格式的接口。
> 文档用法：以「接口名/场景」为条目单位持续追加，每个条目固定四要素——**响应码、响应体、断言表格、断言位置（场景级/步骤级）**。以后每完成一个接口的断言设计，按附录模板追加条目。

## 通用规则（所有条目共同遵守）

### 通用响应格式

| 字段 | 类型 | 是否必须 | 语义 |
|---|---|---|---|
| `is_login` | boolean | 必须 | 用户登录状态，true=已登录 false=未登录 |
| `code` | boolean | 必须 | 响应状态，true=操作成功 false=操作失败 |
| `msg` | string | 必须 | code为false时的错误描述（底层错误，内容不固定） |
| `data` | null/object/array | 非必须 | 业务数据，无返回数据时为 null |
| `time` | number | 必须 | 响应时间，单位：秒 |
| `code_num` | number | 必须 | 返回状态码，0=成功 非0=失败 |
| `code_msg` | string | 必须 | code_num非0时的错误描述信息（语义化描述） |

关键联动关系：`code=true` ⟺ `code_num=0`。

### 断言字段白名单

HTTP响应码、`$.is_login`、`$.code`、`$.code_num`、`$.code_msg`、`$.time`（统一断言大于0），以及具体场景下 `$.data` 内具体字段的值。

- **`$.msg` 一般禁止断言**（底层错误，内容不固定），错误描述断言一律使用 `code_msg`；唯一例外：登录失效场景返回固定 JSON，全字段可断言。
- **值类型用原始值**：`true`/`false`/`0`/`117` 不加引号（加引号会报 `ReferenceError: value is not defined`）。
- **断言对象 path 必填**：必须填写 JSONPath（如 `$.code_num`），禁止"响应体等于xxx"整体断言。
- **两轮断言时机**：首轮不设断言只采集真实响应体回填；第二轮基于真实响应固化断言值后才产生有效通过/失败判定。文中标注「待回填」的值均待首轮真实执行后固化。

### 场景级 vs 步骤级判断标准

**断言值是否全场景统一**：所有步骤预期响应完全一致（如登录失效）→ 场景级通用后置脚本，一次配置全部步骤生效；各接口断言值不同（正常场景、参数异常）→ 步骤级断言组件。

# 第一部分 通用场景断言（跨接口统一，场景级）

## 场景：登录失效（Cookie过期 / 会话被顶替 / 已登出）｜场景 8558577

**响应码**：`200`

**响应体**（固定JSON，真实执行结果）：

```json
{
    "is_login": false,
    "code": false,
    "msg": "please login",
    "data": null,
    "time": 417457.250032845,
    "code_num": 117,
    "code_msg": "please login"
}
```

**断言表格**（除 `time` 外全字段等值断言）：

| 断言名称 | JSONPath | 断言方式 | 断言值 |
|---|---|---|---|
| HTTP状态码为200 | —（HTTP状态码） | 等于 | `200` |
| 登录状态为未登录 | `$.is_login` | 等于 | `false` |
| 操作失败 | `$.code` | 等于 | `false` |
| 错误描述为请登录 | `$.msg` | 等于 | `please login` |
| 无业务数据 | `$.data` | 等于 | `null` |
| 响应时间大于0 | `$.time` | 大于 | `0` |
| 状态码为会话失效 | `$.code_num` | 等于 | `117` |
| 状态码描述为请登录 | `$.code_msg` | 等于 | `please login` |

**断言位置**：场景级通用后置脚本（测试场景 → 通用脚本 → 后置脚本），对场景内每个请求自动运行，测试报告中每个步骤逐条显示断言结果：

```javascript
// token失效场景通用断言：跳过登录/登出等辅助步骤
const path = pm.request.url.getPath();
const skipPaths = ['/v2/login', '/v2/logout'];
if (!skipPaths.some(p => path.includes(p))) {
    pm.test('HTTP状态码为200', () => pm.response.to.have.status(200));
    const res = pm.response.json();
    pm.test('登录状态为未登录', () => pm.expect(res.is_login).to.eql(false));
    pm.test('操作失败', () => pm.expect(res.code).to.eql(false));
    pm.test('错误描述为请登录', () => pm.expect(res.msg).to.eql('please login'));
    pm.test('无业务数据', () => pm.expect(res.data).to.eql(null));
    pm.test('响应时间大于0', () => pm.expect(res.time).to.be.above(0));
    pm.test('状态码为会话失效', () => pm.expect(res.code_num).to.eql(117));
    pm.test('状态码描述为请登录', () => pm.expect(res.code_msg).to.eql('please login'));
}
```

注意：场景内"制造token失效"的辅助步骤（登录、登出、被顶替登录）响应不是失效 JSON，通过 `skipPaths` 数组排除，按场景实际步骤增删。

## 场景：未登录（无Cookie）/ X-Csrf-Token 错误

**响应码**：`403`

**响应体**：HTML 错误页（非 JSON），文本包含 `403 Forbidden`。

**断言表格**：

| 断言名称 | 断言方式 | 断言值 |
|---|---|---|
| HTTP状态码为403 | 等于 | `403` |
| 响应体为HTML错误页 | 文本包含 | `403 Forbidden` |

**禁止配置任何 JSONPath 断言**（响应体不是 JSON，断言本身会报解析错误）。

**断言位置**：场景级通用后置脚本（全场景统一 403 响应时使用）：

```javascript
// 未登录/CSRF错误场景通用断言：跳过登录等辅助步骤
const path = pm.request.url.getPath();
const skipPaths = ['/v2/login', '/v2/logout'];
if (!skipPaths.some(p => path.includes(p))) {
    pm.test('HTTP状态码为403', () => pm.response.to.have.status(403));
    pm.test('响应体为HTML错误页', () => pm.expect(pm.response.text()).to.include('403 Forbidden'));
}
```

## 存储管理模块

### GetPool 获取存储池信息｜`GET /v2/storage/edit/pool/{uuid}`

路径参数：`uuid` = `{{vg0_uuid}}`

#### 场景：正常获取（已登录 + 合法 uuid）

**响应码**：`200`

**响应体**：待回填（首轮真实执行后粘贴完整响应体）

**断言表格**：

| 断言名称 | JSONPath | 断言方式 | 断言值 |
|---|---|---|---|
| HTTP状态码为200 | —（HTTP状态码） | 等于 | `200` |
| 登录状态为已登录 | `$.is_login` | 等于 | `true` |
| 操作成功 | `$.code` | 等于 | `true` |
| 状态码为成功 | `$.code_num` | 等于 | `0` |
| 状态码描述为空 | `$.code_msg` | 等于 | `""` |
| 响应时间大于0 | `$.time` | 大于 | `0` |

`data` 字段暂不处理，后续需要时按场景补充具体字段的等值断言。

**断言位置**：步骤级断言组件。

#### 场景：uuid 不存在（合法格式但不存在，如 `00000000-0000-0000-0000-000000000000`）

**响应码**：`200`

**响应体**：待回填

**断言表格**：

| 断言名称 | JSONPath | 断言方式 | 断言值 |
|---|---|---|---|
| HTTP状态码为200 | —（HTTP状态码） | 等于 | `200` |
| 登录状态为已登录 | `$.is_login` | 等于 | `true` |
| 操作失败 | `$.code` | 等于 | `false` |
| 状态码为对应错误码 | `$.code_num` | 等于 | 待回填固化 |
| 状态码描述正确 | `$.code_msg` | 等于 | 待回填固化 |
| 响应时间大于0 | `$.time` | 大于 | `0` |

不断言 `msg`。

**断言位置**：步骤级断言组件。

#### 场景：uuid 格式非法（如 `abc123`、特殊字符）

**响应码**：`200`

**响应体**：待回填

**断言表格**：结构同「uuid 不存在」，`code_num`/`code_msg` 待回填固化（错误码可能与 uuid 不存在场景不同，分别固化）。

**断言位置**：步骤级断言组件。

#### 场景：uuid 大写（大小写敏感性验证，`{{vg0_uuid}}` 转大写）

**响应码**：`200`

**响应体**：待回填

**断言表格**：

| 断言名称 | JSONPath | 断言方式 | 断言值 |
|---|---|---|---|
| HTTP状态码为200 | —（HTTP状态码） | 等于 | `200` |
| 操作结果 | `$.code` | 等于 | 以真实执行结果为准（敏感=`false`，不敏感=`true`） |

**断言位置**：步骤级断言组件。

#### 场景：鉴权异常

未登录/CSRF错误、登录失效两类场景不在接口条目内重复，统一引用第一部分对应通用场景断言。
